# Huawei Watch, Wear Engine, Circular UI & Sensor Documentation

Official Huawei Developer documentation for building smartwatch applications and phone-to-watch companion integrations:

1. **HarmonyOS Wear Engine Kit (`wear-engine-harmonyos/`)**: 39 docs — Phone-side & Wearable-side ArkTS P2P messaging, file transfer, device discovery, sensor streaming, template notifications, and `@kit.WearEngine` API reference.
2. **Cross-Platform Wear Engine (`wear-engine-cross-platform/`)**: 172 docs (57 Guides, 115 API References) — Android (Java), iOS (Objective-C/Swift `WearEngineSDK`), and Wearable (JS/Java) SDK guides and class references.
3. **Circular Watch UI & Simulator (`circular-ui-components/`)**: 13 docs — Circular screen ArkUI components (`ArcList`, `ArcListItem`, `ArcSwiper`, `ArcButton`, `ArcSlider`, `ArcScrollBar`, `ArcAlphabetIndexer`) and wearable simulator/device runners.
4. **Watch Sensors & Vibrator (`sensors-and-vibrator/`)**: 37 docs — HarmonyOS **Sensor Service Kit** (`@ohos.sensor`, `@ohos.vibrator`, C APIs, IMU accelerometer/gyroscope/heart-rate sampling, and haptic feedback).

- **Total Documents**: 261
