# Vibrator

#### Overview

Provides APIs for vibrator services to access the vibrator driver. Unified APIs can be used across different devices. It supports multiple vibration modes, strengths, and duration control modes, meeting the requirements such as game vibration feedback and notification reminders, and helping developers improve user experience and interaction effects of apps.

**Since**: 11
