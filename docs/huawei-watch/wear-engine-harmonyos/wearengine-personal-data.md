# Personal Data Processing Information

Huawei is a data processor, but not a data controller. The purpose and method of using data are determined by users.

In personal data processing, Huawei serves as the end user data processor, and you (the developer) serve as the end user data controller. For appropriate and legal processing of personal data, the following are provided:

- List of personal data processed by Huawei
- Guidance for you to help the end user control personal data

#### List of Personal Data Processed by Huawei

Last modified: June 11, 2024

| Personal Data | Purpose | Retention Period |
| --- | --- | --- |
| **Device tag**: basic device information, such as the device name, model, and random identifier | To obtain the paired device list and select the device to communicate with. The data will not be stored locally or on the cloud. | N/A |
| **Wearable device status**: connection status, battery level, and charging status | To query or subscribe to the device status by your phone app. The data will not be stored locally or on the cloud. | N/A |
| **Wearable user status:** heart rate alerts and wearing status | To query or subscribe to the wearable user status by your phone app. The data will not be stored locally or on the cloud. | N/A |
| **Human body sensor data**: HR, ECG, PPG, and other sensor data | To manage the human body sensor status and obtain human body sensor data by your phone app. The data will not be stored locally or on the cloud. | N/A |
| **Motion sensor data:** ACC, GYRO, MAG, and other sensor data | To manage the motion sensor status and obtain motion sensor data by your phone app. The data will not be stored locally or on the cloud. | N/A |
| **Device identifier:** SN | To obtain the SNs of paired devices by your phone app. The data will not be stored locally or on the cloud. | N/A |
