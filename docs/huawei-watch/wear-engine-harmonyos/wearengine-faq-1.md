# If the Project Already Has an App ID, Do I Need to Apply for a New One?

If the app ID has been registered on the HUAWEI Developers official website, you do not need to apply for a new ID. However, you need to ensure that the bundle name, app ID, and certificate fingerprint are the same as those submitted during developer account registration.
