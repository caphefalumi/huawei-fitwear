# Why Is the User Authorization Screen Not Displayed?

- Prompt the user to agree to the privacy statement when they use the HUAWEI Health app for the first time.
- Make sure that function development has been completed by referring to [Requesting User Authorization](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/request_user_authorization).
