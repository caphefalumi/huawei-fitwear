# Overview

Provides the class for managing the Wear Engine permissions.

You can use the client to perform operations for user permission authorization, such as applying for and querying permissions.

#### Class Summary

| Class | Description |
| --- | --- |
| [WESAuthClient](https://developer.huawei.com/consumer/en/doc/connectivity-References/we-ios-wesauthclient-class-0000001897943254) | Client used for permission management. You can use it to perform authorization-related operations for user permissions. |
