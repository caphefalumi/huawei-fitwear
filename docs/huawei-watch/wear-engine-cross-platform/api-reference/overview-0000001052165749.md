# Overview

It provides classes and APIs for sending and receiving messages or files customized by your app.

#### Interface Summary

| Interface | Description |
| --- | --- |
| [PingCallback](https://developer.huawei.com/consumer/en/doc/connectivity-References/pingcallback-0000001058995433) | Callback API for sending ping messages. |
| [Receiver](https://developer.huawei.com/consumer/en/doc/connectivity-References/receiver-0000001059027011) | Monitoring API for receiving messages. |
| [SendCallback](https://developer.huawei.com/consumer/en/doc/connectivity-References/sendcallback-0000001059147015) | Callback API for sending messages. |

#### Class Summary

| Class | Description |
| --- | --- |
| [HiWearMessage](https://developer.huawei.com/consumer/en/doc/connectivity-References/hiwearmessage-0000001059835462) | Message object sent to the peer device. |

| [P2pClient](https://developer.huawei.com/consumer/en/doc/connectivity-References/p2pclient-0000001059995062) | Client for P2P communication. |
