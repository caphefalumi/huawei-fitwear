# Overview

It provides classes for reporting events and querying status of Wear Engine.

#### Interface Summary

| Interface | Description |
| --- | --- |
| [MonitorListener](https://developer.huawei.com/consumer/en/doc/connectivity-References/monitorlistener-0000001059850655) | API for listening for event reporting. |

#### Class Summary

| Class | Description |
| --- | --- |
| [MonitorClient](https://developer.huawei.com/consumer/en/doc/connectivity-References/monitorclient-0000001059980975) | Indicates a client used for event reporting and status query, for example, it listens for the connection status between a device and the Huawei Health app. |
| [MonitorData](https://developer.huawei.com/consumer/en/doc/connectivity-References/monitordata-0000001060779124) | Converts the listened indicators to operable data, such as Boolean, Integer, String, and HashMap data. |
| [MonitorItem](https://developer.huawei.com/consumer/en/doc/connectivity-References/monitoritem-0000001059433013) | Listens for the indicator objects of the device, such as the connection status between the device and the Huawei Health app. |
