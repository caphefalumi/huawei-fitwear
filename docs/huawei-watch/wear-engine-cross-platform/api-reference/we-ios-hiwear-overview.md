# Overview

Provides the entry classes for Wear Engine.

Used to obtain client instances for the Wear Engine capabilities, such as **WESDeviceClient** and **WESP2PClient**.

#### Class Summary

| Class | Description |
| --- | --- |
| [HiWear](https://developer.huawei.com/consumer/en/doc/connectivity-References/we-ios-hiwear-0000001897479338) | General entrance to the Wear Engine capabilities. It is used to obtain client instances that use the Wear Engine capabilities, such as **WESDeviceClient** and **WESP2PClient**. |
