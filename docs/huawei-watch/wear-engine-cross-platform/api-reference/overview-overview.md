# Overview

It provides the entry classes for Wear Engine.

It is used to obtain client instances that use the Wear Engine capabilities, such as DeviceClient and P2pClient.

#### Class Summary

| Class | Description |
| --- | --- |
| [HiWear](https://developer.huawei.com/consumer/en/doc/connectivity-References/hiwear-0000001060938716) | As a general entrance to the Wear Engine capabilities, it is used to obtain client instances that use the Wear Engine capabilities, such as DeviceClient and P2pClient. |
