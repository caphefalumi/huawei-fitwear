# Overview

It provides the class for the Wear Engine P2P communication functions.

#### Interface Summary

| Interface | Description |
| --- | --- |
| [PingCallback](https://developer.huawei.com/consumer/en/doc/connectivity-References/pingcallback-0000001060938728) | Callback API of ping messages. |
| [Receiver](https://developer.huawei.com/consumer/en/doc/connectivity-References/receiver-0000001060460920) | Monitoring API for P2P communication. |
| [SendCallback](https://developer.huawei.com/consumer/en/doc/connectivity-References/sendcallback-0000001059290639) | Callback API for sending messages. |
| [CancelFileTransferCallBack](https://developer.huawei.com/consumer/en/doc/connectivity-References/cancelfiletransfercallback-0000001093458245) | Callback API for canceling sending files. |

#### Class Summary

| Class | Description |
| --- | --- |
| [Message](https://developer.huawei.com/consumer/en/doc/connectivity-References/message-0000001059781033) | Message object for communicating with the phone. |
| [Message.Builder](https://developer.huawei.com/consumer/en/doc/connectivity-References/message_builder-0000001059850659) | Building class in Message. |
| [P2pClient](https://developer.huawei.com/consumer/en/doc/connectivity-References/p2pclient-0000001061098712) | Client used for P2P communication |
| [Peer](https://developer.huawei.com/consumer/en/doc/connectivity-References/peer-0000001060460922) | Message object of the device that needs to be communicated with. |
| [Peer.Builder](https://developer.huawei.com/consumer/en/doc/connectivity-References/peer_builder-0000001059290641) | Internal building class in Peer. |
| [FileIdentification](https://developer.huawei.com/consumer/en/doc/connectivity-References/fileidentification-0000001077679542) | File identifier object input by the user when the file transfer is stopped. |
| [FileIdentification.Builder](https://developer.huawei.com/consumer/en/doc/connectivity-References/fileidentification_builder-0000001093318165) | Internal building class of FileIdentification. |
