# Overview

It provides classes for Wear Engine to operate the devices.

#### Class Summary

| Class | Description |
| --- | --- |
| [Device](https://developer.huawei.com/consumer/en/doc/connectivity-References/device-0000001059980971) | Data class returned by the wearable device that is integrated with Wear Engine. |
| [DeviceClient](https://developer.huawei.com/consumer/en/doc/connectivity-References/deviceclient-0000001060779120) | The client that is used to operate the device. |
