# SendCallback

```
public interface SendCallback
```

It is the callback API for sending messages.

It is used to call back the sending result after the wearable device sends a message to the phone.

#### Method Summary

| Modifier and Type | Method and Description |
| --- | --- |
| default void | [onSendProgress](https://developer.huawei.com/consumer/en/doc/connectivity-References/sendcallback-0000001059147015#EN-US_TOPIC_0000001873951310__onSendProgress-long-)(long count) Indicates the callback function for the message sending progress. |
| void | [onSendResult](https://developer.huawei.com/consumer/en/doc/connectivity-References/sendcallback-0000001059147015#EN-US_TOPIC_0000001873951310__onSendResult-int-)(int errCode) Indicates the callback function for the message sending result. |

#### Method Detail

## onSendResult

void onSendResult(int errCode)

It indicates the callback function of the message sending result.

**Parameters:**

| Parameter Name | Parameter Description |
| --- | --- |
| errCode | Result code, which is the same as [HiWearErrorCode](https://developer.huawei.com/consumer/en/doc/connectivity-References/hiwearerrorcode-0000001058717345). |

## onSendProgress

default void onSendProgress(long count)

It indicates the callback function for the message sending progress.

**Parameters:**

| Parameter Name | Parameter Description |
| --- | --- |
| count | Indicates progress value. The value ranges from 0 to 100. It is displayed only during file sending. |
