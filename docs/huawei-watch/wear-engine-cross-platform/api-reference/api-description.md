# Description

| Application Scenario | Name | Description |
| --- | --- | --- |
| Phone | Android | APIs for Android apps on phones, based on the Java language, enable apps or services on phones to send messages and notifications and transmit data to wearable devices, as well as obtain the status of wearable devices. |
| Phone | iOS | APIs for Android apps on phones, based on the Java language, enable apps or services on phones to send messages and notifications and transmit data to wearable devices, as well as obtain the status of wearable devices. |
| Wearable device | HarmonyOS | • APIs for HarmonyOS apps on **lite wearable devices** and **smart wearable devices**, based on the JavaScript language, enable apps or services on these wearable devices to send messages and transmit data to phones. • APIs for HarmonyOS apps on **smart wearable devices**, based on the Java language, enable apps or services on these wearable devices to send messages and transmit data to phones. |
