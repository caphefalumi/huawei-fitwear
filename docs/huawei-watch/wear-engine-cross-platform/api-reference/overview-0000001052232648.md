# Overview

It provides the class for managing the Wear Engine permissions.

You can use the client to perform operations for user permission authorization, such as applying for and querying permissions.

#### Interface Summary

| Interface | Description |
| --- | --- |
| [AuthCallback](https://developer.huawei.com/consumer/en/doc/connectivity-References/authcallback-0000001059850647) | Permission callback API. |

#### Class Summary

| Class | Description |
| --- | --- |
| [AuthClient](https://developer.huawei.com/consumer/en/doc/connectivity-References/authclient-0000001059980967) | Client used for permission management. You can use the client to perform operations for user permission authorization. |
| [Permission](https://developer.huawei.com/consumer/en/doc/connectivity-References/permission-0000001059433005) | Permission object of Wear Engine. It encapsulates the permissions specified by Wear Engine. Currently, the **DEVICE_MANAGER**, **NOTIFY**, and **WEAR_USER_STATUS** permissions are included. |
