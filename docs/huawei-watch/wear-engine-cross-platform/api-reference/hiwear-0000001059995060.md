# HiWear

java.lang.Object

|---com.huawei.watch.kit.hiwear.HiWear

```
public final class HiWear
extends java.lang.Object
```

It is the general entrance to the Wear Engine capabilities.

It is used to obtain the client instances in which the Wear Engine capabilities are used, such as **P2pClient** and **PeerDeviceClient**.
