# Version Change History

Lite wearable devices: Only the JS language is currently used for app development.

Smart wearable devices: Both the JS and [Java](https://developer.huawei.com/consumer/en/doc/connectivity-Guides/version-change-history-0000001119036892) languages can be used for app development.

#### Lite Wearable Devices

## 5.0.2.306 (2022-02-09)

| **New Features:** Querying the phone system: Added support for querying the system type of the phone connected to the wearable device. |
| --- |

> **Note:** The lite wearable device version must be HarmonyOS 2.1.0.201 or later.

## Earlier Versions

**5.0.2.300 (2021-04-27)**

| **Modified Features:** [App-to-App Message Communications](https://developer.huawei.com/consumer/en/doc/connectivity-Guides/send-message-0000001052460491): Added support for using the relative path **internal://app/** to send files. **New Features:** [App-to-App Message Communications](https://developer.huawei.com/consumer/en/doc/connectivity-Guides/send-message-0000001052460491): Added support for using the **setPeerPkgName()** and **setPeerFingerPrint()** APIs to specify the package name and fingerprint information of your phone app during app running. |
| --- |

> **Note:** The lite wearable device version must be 11.0.5 or later.

**5.0.1.300 (2020-12-25)**

| **New Features:** [App-to-App Message Communications](https://developer.huawei.com/consumer/en/doc/connectivity-Guides/send-message-0000001052460491): Added support for receiving files sent from your phone app and sending files to your phone app. |
| --- |

> **Note:** Requires the lite wearable device version 10.1 or later.

**5.0.0.300 (2020-09-25)**

| Huawei Health has introduced the brand new Wear Engine-LiteWearable-5.0.0.300. This update added new features such as allowing your phone app to obtain a list of connected lite wearable devices and subscribe to their connection status; and added support for P2P messaging between your phone app and lite wearable app and P2P file transfers from your phone app to the lite wearable app. Update Wear Engine to try it out! |
| --- |

> **Note:** Requires the lite wearable device version 10.1 or later.

#### Smart Wearable Devices

## 5.0.2.306 (2022-02-09)

| **New Features:** Querying the phone system: Added support for querying the system type of the phone connected to the wearable device. |
| --- |

> **Note:** The smart wearable device version must be 2.0.0.216 or later.

## Earlier Versions

**5.0.2.302 (2021-08-24)**

| Huawei Health has introduced the brand new Wear Engine-Wearable-5.0.2.302. This update added support for P2P messaging and file transfers between your phone app and smart wearable app, as well as calling the **ping** method on your phone app to launch your smart wearable app. Update Wear Engine to try it out! |
| --- |

> **Note:** The smart wearable device version must be 2.0.0.170 or later.
