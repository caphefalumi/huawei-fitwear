# Version Change History

#### 1.0.0.304 (2026-05-08)

| **New Features** Adapted to scenarios where users do not select any device permissions on the authorization page, and added support for universal link redirection authorization. |
| --- |

> **Note:** The Huawei Health app must be version 15.0.10.315 or later.

#### Earlier Versions

## 1.0.0.302 (2025-05-27)

| **New Features** Added the capability of connecting to smart watches. |
| --- |

> **Note:** The Huawei Health app must be version 15.0.10.315 or later.

## 1.0.0.301 (2024-12-10)

| **New Features** Optimized the result returned by the API for obtaining the device list. The returned device list data is now the same as that displayed in the Huawei Health app. |
| --- |

> **Note:** The Huawei Health app must be version 14.1.6.305 or later.

## 1.0.0.300 (2024-07-02)

| **New Features** Added the iOS phone app development guide. |
| --- |

> **Note:** The Huawei Health app must be version 14.1.6.305 or later.
