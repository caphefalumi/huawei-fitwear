# Registering a HUAWEI ID and Applying for the HUAWEI ID Service

- Register as a developer and complete identity verification. For detailed operations, refer to [HUAWEI ID Registration](https://developer.huawei.com/consumer/en/doc/start/registration-and-verification-0000001053628148). Figure 1 **Registering as a developer
- Sign in to the [HUAWEI Developers](https://developer.huawei.com/consumer/en/) website and click **Console**. **Figure 2 **Clicking **Console**
- Click **AppGallery Connect**. **Figure 3 **Clicking AppGallery Connect
- Add a project under **Development & services**. **Figure 4 **Click **Development & services**. **Figure 5 **Click **Add project**.**
- Enter the project name, select whether to enable HUAWEI Analytics (optional), and finish creating the project. Figure 6 **Entering a project name to create a project
- Add an app to the project. Select **iOS** and enter the app package ID and app name. **Figure 7 **Adding an app to the project **Figure 8 **Selecting **iOS** and entering the app package ID and app name
- After creating an iOS app, add a callback URL to the app. Enter the dedicated callback URL (https://h5hosting.dbankcdn.com/cch5/healthkit/oauth-h5/oauth-callback.html) for Wear Engine in the app configuration as shown in the following figure. Note that a client secret is required when [requesting user authorization](https://developer.huawei.com/consumer/en/doc/connectivity-Guides/request-user-authorization-ios-0000001920933293).
- Click **OK** to finish creating the iOS app. Next, proceed to [Applying for the Wear Engine Service](https://developer.huawei.com/consumer/en/doc/connectivity-Guides/applying-wearengine-ios-0000001935664117).
