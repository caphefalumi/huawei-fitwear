# Personal Data Processing Information

Huawei is a data processor, but not a data controller. The purpose and method of using data are determined by users.

Huawei serves as the end user data processor and you (the developer) serve as the end user data controller. For appropriate and legal processing of personal data, the following are provided:

- List of personal data processed by Huawei
- Guidance for you to help the end user control personal data

#### List of Personal Data Processed by Huawei

Last updated: February 25, 2026

| Personal Data | Purpose of Use | Retention Period |
| --- | --- | --- |
| **Device name**, mutable device identifier (device ID), device model, device type, OS information, and **SN** | **For your phone app to obtain the paired device list and select the device that requires the communications. Data will not be stored locally or on the cloud.** | **N/A** |
| Battery level, charging status, storage space status, device wearing status, and device connection status | For your phone app to query or subscribe to the device status. Data will not be stored locally or on the cloud. | N/A |

#### Guidance for You to Help the End User Control Personal Data

Users can grant, view, or cancel the authorization of your app by going to Huawei Health > Me** > **Settings** > **Device capabilities**.

iPhone users can grant, view, or cancel the authorization of your app by going to **HUAWEI Health** > **Me**, touching the profile picture, and going to **Privacy center** > **Control account access**.
