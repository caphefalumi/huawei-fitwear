# App-to-App Message Communications

This API is used to establish the communications channel between your phone app and the wearable app, to receive and send packet messages and files customized by your app.

#### Checking Whether Your App Has Been Installed on the Phone

Before sending a P2P message, you can use the **ping** method to check whether your wearable app can communicate with the phone app.

- Call the [getP2pClient](https://developer.huawei.com/consumer/en/doc/connectivity-References/hiwear-0000001059995060#EN-US_TOPIC_0000001920110329__getP2pClient-ohos_app_Context-) method in [HiWear](https://developer.huawei.com/consumer/en/doc/connectivity-References/hiwear-0000001059995060) to obtain the [P2pClient](https://developer.huawei.com/consumer/en/doc/connectivity-References/p2pclient-0000001059995062) object.
- Call the [setPeerPkgName](https://developer.huawei.com/consumer/en/doc/connectivity-References/p2pclient-0000001059995062#EN-US_TOPIC_0000001874111170__setPeerPkgName-java_lang_String-) method and specify the package name of your phone app to be communicated with using the **ping** method.
- Call the [ping](https://developer.huawei.com/consumer/en/doc/connectivity-References/p2pclient-0000001059995062#EN-US_TOPIC_0000001874111170__ping-com_huawei_watch_kit_hiwear_p2p_PingCallback-) method to check whether your app has been installed on the phone. If the app has not been installed on the phone, result code **204** will be returned. If the app has been installed on the phone, result code **205** will be returned. 
```cpp
// Step 1: Obtain the P2P communication object.
P2pClient p2pClient = HiWear.getP2pClient(this);
String peerPkgName = "com.*.*";

// Step 2: Set the package name of your phone app to be communicated with.
p2pClient.setPeerPkgName(peerPkgName);

// Step 3: Check whether your phone app is running.
p2pClient.ping(new PingCallback() {
    @Override
    public void onResult(int i) {
        // Callback result
    }
});
```

#### Sending P2P Messages or Files to Your Phone App

The maximum size of a message is 1 KB. If the size of a message exceeds the limit, the message can be divided into several packets or files (with each no larger than 4 MB) can be sent instead.

If the wearable app is able to send messages and files, the phone app must support receiving these messages and files. For details, see [Receiving P2P messages or files sent by your wearable app](https://developer.huawei.com/consumer/en/doc/connectivity-Guides/phone-send-message-0000001051059209#section11891149183312) on the phone.

## Sending P2P Messages

- Call the [getP2pClient](https://developer.huawei.com/consumer/en/doc/connectivity-References/hiwear-0000001059995060#EN-US_TOPIC_0000001920110329__getP2pClient-ohos_app_Context-) method in [HiWear](https://developer.huawei.com/consumer/en/doc/connectivity-References/hiwear-0000001059995060) to obtain the [P2pClient](https://developer.huawei.com/consumer/en/doc/connectivity-References/p2pclient-0000001059995062) object.
- Call the [setPeerPkgName](https://developer.huawei.com/consumer/en/doc/connectivity-References/p2pclient-0000001059995062#EN-US_TOPIC_0000001874111170__setPeerPkgName-java_lang_String-) method and specify the package name of your phone app to be communicated with.
- Call the [setPeerFingerPrint](https://developer.huawei.com/consumer/en/doc/connectivity-References/p2pclient-0000001059995062#EN-US_TOPIC_0000001874111170__setPeerFingerPrint-java_lang_String-) method and specify the fingerprint SHA-256 information of your phone app to be communicated with. (Refer to [Generating a Signing Certificate Fingerprint](https://developer.huawei.com/consumer/en/codelab/HMSPreparation/index.html#3) to obtain an SHA-256 certificate fingerprint. The fingerprint is one of the fingerprints registered by your phone app when applying for the HUAWEI ID Service from HUAWEI Developers, that is, one of the SHA-256 certificate fingerprints in Step 4 in [Registering a HUAWEI ID and Applying for the HUAWEI ID Service](https://developer.huawei.com/consumer/en/doc/connectivity-Guides/registering-applying-account-0000001050818011).)
- Call the [send](https://developer.huawei.com/consumer/en/doc/connectivity-References/p2pclient-0000001059995062#EN-US_TOPIC_0000001874111170__send-com_huawei_watch_kit_hiwear_p2p_HiWearMessage-com_huawei_watch_kit_hiwear_p2p_SendCallback-) method to send short messages from your wearable app to the phone app. Call the [HiWearMessage](https://developer.huawei.com/consumer/en/doc/connectivity-References/hiwearmessage-0000001059835462) object to define messages that need to be sent by your app.
- Call the [onSendProgress](https://developer.huawei.com/consumer/en/doc/connectivity-References/sendcallback-0000001059147015#EN-US_TOPIC_0000001873951310__onSendProgress-long-)(long progress) method to check the sending progress.
- Call the [onSendResult](https://developer.huawei.com/consumer/en/doc/connectivity-References/sendcallback-0000001059147015#EN-US_TOPIC_0000001873951310__onSendResult-int-)(int resultCode) method to return results: success or failure.

```cpp
// Step 1: Obtain the P2P communication object.
P2pClient p2pClient = HiWear.getP2pClient(this);
String peerPkgName = "com.*.*";
String peerFinger = "67DFB7FD********";

// Step 2: Set the package name of your phone app to be communicated with.
p2pClient.setPeerPkgName(peerPkgName);

// Step 3: Set the app fingerprint information on the phone.
p2pClient.setPeerFingerPrint(peerFinger);

// Step 4: Send a short message to your phone app.
// Build a Message object.
String messageStr = "Hello, Wear Engine!";
HiWearMessage.Builder builder = new HiWearMessage.Builder();
builder.setPayload(messageStr.getBytes("UTF-8"));
HiWearMessage sendMessage = builder.build();
// Create the callback method.
SendCallback sendCallback = new SendCallback() {
    @Override
    public void onSendResult(int resultCode) {
    }
    @Override
    public void onSendProgress(long progress) {
    }
};
if (sendMessage != null && sendCallback != null) {
    p2pClient.send(sendMessage, sendCallback);
}
```

## Sending Files

- Call the [getP2pClient](https://developer.huawei.com/consumer/en/doc/connectivity-References/hiwear-0000001059995060#EN-US_TOPIC_0000001920110329__getP2pClient-ohos_app_Context-) method in [HiWear](https://developer.huawei.com/consumer/en/doc/connectivity-References/hiwear-0000001059995060) to obtain the [P2pClient](https://developer.huawei.com/consumer/en/doc/connectivity-References/p2pclient-0000001059995062) object.
- Call the [setPeerPkgName](https://developer.huawei.com/consumer/en/doc/connectivity-References/p2pclient-0000001059995062#EN-US_TOPIC_0000001874111170__setPeerPkgName-java_lang_String-) method and specify the package name of your phone app to be communicated with.
- Call the [setPeerFingerPrint](https://developer.huawei.com/consumer/en/doc/connectivity-References/p2pclient-0000001059995062#EN-US_TOPIC_0000001874111170__setPeerFingerPrint-java_lang_String-) method and specify the fingerprint SHA-256 information of your phone app to be communicated with. (Refer to [Generating a Signing Certificate Fingerprint](https://developer.huawei.com/consumer/en/codelab/HMSPreparation/index.html#3) to obtain an SHA-256 certificate fingerprint. The fingerprint is one of the fingerprints registered by your phone app when applying for the HUAWEI ID Service from HUAWEI Developers, that is, one of the SHA-256 certificate fingerprints in Step 4 in [Registering a HUAWEI ID and Applying for the HUAWEI ID Service](https://developer.huawei.com/consumer/en/doc/connectivity-Guides/registering-applying-account-0000001050818011).)
- Call the [send](https://developer.huawei.com/consumer/en/doc/connectivity-References/p2pclient-0000001059995062#EN-US_TOPIC_0000001874111170__send-com_huawei_watch_kit_hiwear_p2p_HiWearMessage-com_huawei_watch_kit_hiwear_p2p_SendCallback-) method to send files from your wearable app to the phone app. Call the [HiWearMessage](https://developer.huawei.com/consumer/en/doc/connectivity-References/hiwearmessage-0000001059835462) object to define files that need to be sent by your app.
- Call the [onSendProgress](https://developer.huawei.com/consumer/en/doc/connectivity-References/sendcallback-0000001059147015#EN-US_TOPIC_0000001873951310__onSendProgress-long-)(long progress) method to check the sending progress.
- Call the [onSendResult](https://developer.huawei.com/consumer/en/doc/connectivity-References/sendcallback-0000001059147015#EN-US_TOPIC_0000001873951310__onSendResult-int-)(int resultCode) method to return results: success or failure.

```cpp
// Step 1: Obtain the P2P communication object
P2pClient p2pClient = HiWear.getP2pClient(this);
String peerPkgName = "com.*.*";
String peerFinger = "67DFB7FD********";

// Step 2: Set the package name of your phone app to be communicated with.
p2pClient.setPeerPkgName(peerPkgName);

// Step 3: Set the app fingerprint information on the phone.
p2pClient.setPeerFingerPrint(peerFinger);

// Step 4: Send a file to the phone app.
// Build a file to be sent.
String filePath = ".....";
File sendFile = new File(filePath);
HiWearMessage.Builder builder = new HiWearMessage.Builder();
builder.setPayload(sendFile);
HiWearMessage sendMessage = builder.build();
// Create the callback method.
SendCallback sendCallback = new SendCallback() {
    @Override
    public void onSendResult(int resultCode) {
    }
    @Override
    public void onSendProgress(long progress) {
    }
};
if (sendMessage != null && sendCallback != null) {
    p2pClient.send(sendMessage, sendCallback);
}
```

## Receiving P2P Messages or Files from Your Phone App

- Call the [getP2pClient](https://developer.huawei.com/consumer/en/doc/connectivity-References/hiwear-0000001059995060#EN-US_TOPIC_0000001920110329__getP2pClient-ohos_app_Context-) method in [HiWear](https://developer.huawei.com/consumer/en/doc/connectivity-References/hiwear-0000001059995060) to obtain the [P2pClient](https://developer.huawei.com/consumer/en/doc/connectivity-References/p2pclient-0000001059995062) object.
- Call the [setPeerPkgName](https://developer.huawei.com/consumer/en/doc/connectivity-References/p2pclient-0000001059995062#EN-US_TOPIC_0000001874111170__setPeerPkgName-java_lang_String-) method and specify the package name of your phone app to be communicated with.
- Call the [setPeerFingerPrint](https://developer.huawei.com/consumer/en/doc/connectivity-References/p2pclient-0000001059995062#EN-US_TOPIC_0000001874111170__setPeerFingerPrint-java_lang_String-) method and specify the fingerprint SHA-256 information of your phone app to be communicated with. (Refer to [Generating a Signing Certificate Fingerprint](https://developer.huawei.com/consumer/en/codelab/HMSPreparation/index.html#3) to obtain an SHA-256 certificate fingerprint. The fingerprint is one of the fingerprints registered by your phone app when applying for the HUAWEI ID Service from HUAWEI Developers, that is, one of the SHA-256 certificate fingerprints in Step 4 in [Registering a HUAWEI ID and Applying for the HUAWEI ID Service](https://developer.huawei.com/consumer/en/doc/connectivity-Guides/registering-applying-account-0000001050818011).)
- Call the [registerReceiver](https://developer.huawei.com/consumer/en/doc/connectivity-References/p2pclient-0000001059995062#EN-US_TOPIC_0000001874111170__registerReceiver-com_huawei_watch_kit_hiwear_p2p_Receiver-) method to allow your wearable app to receive short messages or files from the phone app. The principle behind this is to register a listener for Wear Engine. Call the [onReceiveMessage](https://developer.huawei.com/consumer/en/doc/connectivity-References/receiver-0000001059027011#EN-US_TOPIC_0000001919950665__onReceiveMessage-com_huawei_watch_kit_hiwear_p2p_HiWearMessage-) method to deal with messages or files sent from the phone app. The received file is stored under the **data/data/{packageName}/cache/hiwear** directory by default. 
```cpp
// Step 1: Obtain the P2P communication object.
P2pClient p2pClient = HiWear.getP2pClient(this);
String peerPkgName = "com.*.*";
String peerFinger = "67DFB7FD********";

// Step 2: Set the package name of your phone app to be communicated with.
p2pClient.setPeerPkgName(peerPkgName);

// Step 3: Set the app fingerprint information on the phone.
p2pClient.setPeerFingerPrint(peerFinger);

// Step 4: Receive short messages or files from your phone app.
Receiver receiver = new Receiver() {
     @Override
     public void onReceiveMessage(HiWearMessage message) {
          // Process short messages and files sent by your phone app.
     }
};
p2pClient.registerReceiver(receiver);
```

- Call the [unregisterReceiver](https://developer.huawei.com/consumer/en/doc/connectivity-References/p2pclient-0000001059995062#EN-US_TOPIC_0000001874111170__unregisterReceiver-com_huawei_watch_kit_hiwear_p2p_Receiver-) method to cancel the reception of messages or files sent from your phone app. The principle behind this is to unregister a listener for Wear Engine. 
```cpp
// Step 5: Cancel the reception of messages or files from your phone app.
p2pClient.unregisterReceiver(receiver);
```

#### Launching the App on the Wearable by Calling the Ping Method on the Phone App

If the phone app is launched while the wearable app is not, the phone app can launch the latter by using the **ping** method. To use this function, the app on the wearable device must create the Page Ability of a specified name.

- Create the Page Ability on the wearable device and name it **HiWearMainAbility.java**. Call the **setMainRoute** method in **onStart** to specify the corresponding interface. 
```cpp
public class HiWearMainAbility extends Ability {
    @Override    
    public void onStart(Intent intent) {
        super.onStart(intent);
        super.setMainRoute(MainAbilitySlice.class.getName());
    }
}
```
 > **Note:** The name of the Ability is **HiWearMainAbility.java**, which cannot be customized.
- Declare the Ability in the **config.json** file. Set **type** to **page** and **visible** to **true**. 
```cpp
"abilities": [ 
  ...... 
  {
    ......
    "visible": true,
    "name": ".HiWearMainAbility",
    "type": "page",
    ......
  }, 
  ...... 
],
```

- After the preceding configuration is complete, use the [ping](https://developer.huawei.com/consumer/en/doc/connectivity-References/p2pclient-0000001061098712#EN-US_TOPIC_0000001920110385__ping-com_huawei_wearengine_device_Device-com_huawei_wearengine_p2p_PingCallback-) method on the phone to start the wearable app. For details, please refer to [Checking Whether the Wearable App is Running](https://developer.huawei.com/consumer/en/doc/connectivity-Guides/phone-send-message-0000001051059209#section25081840087).
