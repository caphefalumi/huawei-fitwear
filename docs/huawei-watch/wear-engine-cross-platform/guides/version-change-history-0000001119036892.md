# Version Change History

The Java SDK only applies to developing apps for smart wearable devices while the [JS language](https://developer.huawei.com/consumer/en/doc/connectivity-Guides/version-change-history-0000001133580285) applies to developing apps for lite wearable devices.

#### 5.0.2.306 (2022-02-09)

| **New Features:** Querying the phone system: Added [getPeerDevice](https://developer.huawei.com/consumer/en/doc/connectivity-References/peerdeviceclient-0000001192908020#EN-US_TOPIC_0000001873951294__getPeerDevice-com_huawei_watch_kit_hiwear_peerdevice_PeerDeviceCallback-) to query the system type of the phone connected to the wearable device. |
| --- |

> **Note:** Requires the smart wearable device version 2.0.0.216 or later.

#### Earlier Versions

## 5.0.2.302 (2021-08-24)

| Huawei Health has introduced the brand new Wear Engine-Wearable-5.0.2.302. This update added support for P2P messaging and file transfers between your phone app and smart wearable app, as well as calling the **ping** method on your phone app to launch your smart wearable app. Update Wear Engine to try it out! |
| --- |

> **Note:** Requires the smart wearable device version 2.0.0.170 or later.
