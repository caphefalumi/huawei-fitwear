# Managing Data Sources

#### Use Cases

A data source provides app or device information. Each piece of health and fitness data must be associated with a data source via a **DataSourceId**.

> **Note:** The value of **DataSourceId** is generated by the platform when the data source information is inserted and cannot be changed.

#### API Description

| API | Description |
| --- | --- |
| [insertDataSource](https://developer.huawei.com/consumer/en/doc/harmonyos-references/health-api-healthstore#healthstoreinsertdatasource)(dataSource: [DataSourceBase](https://developer.huawei.com/consumer/en/doc/harmonyos-references/health-api-healthstore#datasourcebase)): Promise<string> | Inserts a data source. The input parameter is the data source base class [DataSourceBase](https://developer.huawei.com/consumer/en/doc/harmonyos-references/health-api-healthstore#datasourcebase). |
| [readDataSource](https://developer.huawei.com/consumer/en/doc/harmonyos-references/health-api-healthstore#healthstorereaddatasource)(request: [DataSourceReadRequest](https://developer.huawei.com/consumer/en/doc/harmonyos-references/health-api-healthstore#datasourcereadrequest)): Promise<[DataSource](https://developer.huawei.com/consumer/en/doc/harmonyos-references/health-api-healthstore#datasource)[]> | Queries data sources. You can use [DataSourceReadRequest](https://developer.huawei.com/consumer/en/doc/harmonyos-references/health-api-healthstore#datasourcereadrequest) to set query conditions and query data by **DataSourceId**, bundle name, or **UniqueId** of the device. |
| [updateDataSource](https://developer.huawei.com/consumer/en/doc/harmonyos-references/health-api-healthstore#healthstoreupdatedatasource)(dataSource: [DataSource](https://developer.huawei.com/consumer/en/doc/harmonyos-references/health-api-healthstore#datasource)): Promise<void> | Updates a data source. Note that the **dataSourceId** and **uniqueId** fields cannot be updated. |

#### Before Getting Started

- Complete the operations in [Applying for Health Service Kit](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/health-apply) and [Configuring the Client ID](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/health-configuration-client-id).
- Before calling an API for the first time, call the [init](https://developer.huawei.com/consumer/en/doc/harmonyos-references/health-api-healthstore#healthstoreinit) method to perform initialization.
- Make sure that you have obtained users' authorization for your app to access any data type by calling the API for [requesting user authorization](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/health-add-permissions#requesting-user-authorization), before calling the relevant data source APIs.
- For details about error codes, please refer to [ArkTS API Error Codes](https://developer.huawei.com/consumer/en/doc/harmonyos-references/errorcode-healthservice). For FAQs, please refer to [FAQs About Health Service Kit](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/health-faqs).

#### Development Procedure

## Inserting a Data Source

- Import the Health Service Kit functional module and related common modules. 
```typescript
import { healthStore } from '@kit.HealthServiceKit';
import { hilog } from '@kit.PerformanceAnalysisKit';
```

- Create a data source. 
```typescript
let dataSource: healthStore.DataSourceBase = {
  deviceInfo: {
    uniqueId: 'test',
    name: 'test', // This field is mandatory when a data source is inserted.
    category: healthStore.DeviceCategory.WEARABLE_BAND, // This field is mandatory when a data source is inserted.
    productId: '0554', // This field is mandatory when a data source is inserted.
    model: 'lotana',
    manufacturer: 'HUAWEI',
    mac: 'testDeviceMac',
    sn: 'testDeviceSn',
    hardwareVersion: '1',
    softwareVersion: '2',
    firmwareVersion: '3',
    udid: ''
  }
}
```

- Call [insertDataSource](https://developer.huawei.com/consumer/en/doc/harmonyos-references/health-api-healthstore#healthstoreinsertdatasource) to insert a data source and process the returned result. 
```typescript
try {
  const dataSourceId = await healthStore.insertDataSource(dataSource);
  hilog.info(0x0000, 'testTag', `Succeeded in inserting dataSource, the dataSourceId is ${dataSourceId}.`);
} catch (err) {
  hilog.error(0x0000, 'testTag', `Failed to insert dataSource. Code: ${err.code}, message: ${err.message}`);
}
```

## Reading Data Sources

- Import the Health Service Kit functional module and related common modules. 
```typescript
import { healthStore } from '@kit.HealthServiceKit';
import { hilog } from '@kit.PerformanceAnalysisKit';
```

- Create a data source read request. 
```typescript
let readSourceRequest: healthStore.DataSourceReadRequest = {
  deviceUniqueId: 'testudidupdate'
}
```

- Call [readDataSource](https://developer.huawei.com/consumer/en/doc/harmonyos-references/health-api-healthstore#healthstorereaddatasource) to query the data sources and process the returned result. 
```typescript
try {
  let dataSources = await healthStore.readDataSource(readSourceRequest);
  dataSources.forEach((dataSource) => {
    hilog.info(0x0000, 'testTag', `Succeeded in reading dataSource, the dataSourceId is ${dataSource.dataSourceId}.`);
  });
} catch (err) {
  hilog.error(0x0000, 'testTag', `Failed to read dataSource. Code: ${err.code}, message: ${err.message}`);
}
```

## Updating a Data Source

- Import the Health Service Kit functional module and related common modules. 
```typescript
import { healthStore } from '@kit.HealthServiceKit';
import { hilog } from '@kit.PerformanceAnalysisKit';
```

- Create a data source. 
```typescript
let newDataSource: healthStore.DataSource = {
  deviceInfo: {
    uniqueId: 'test',
    name: 'test',
    category: healthStore.DeviceCategory.WEARABLE_BAND,
    productId: '0554',
    model: 'lotana',
    manufacturer: 'HUAWEI',
    mac: 'testDeviceMac',
    sn: 'testDeviceSn',
    hardwareVersion: '1',
    softwareVersion: '2',
    firmwareVersion: '3',
    // Update the UDID.
    udid: 'updateudid'
  },
  // The value of dataSourceId is that returned when the data source is inserted.
  dataSourceId: 'xxx'
}
```

- Call [updateDataSource](https://developer.huawei.com/consumer/en/doc/harmonyos-references/health-api-healthstore#healthstoreupdatedatasource) to update the data source and process the returned result. 
```typescript
try {
  await healthStore.updateDataSource(newDataSource);
  hilog.info(0x0000, 'testTag', 'Succeeded in updating dataSource.');
} catch (err) {
  hilog.error(0x0000, 'testTag', `Failed to update dataSource. Code: ${err.code}, message: ${err.message}`);
}
```
