# exerciseSequenceHelper (Workout Record Type Constants) (Lite)

This module provides data type constants and data models of workout records.

**Since:** 6.1.1(24)

#### Modules to Import

```javascript
import healthStore from '@hms.health.store';
```

> **Note:** This module is a sub-module of **healthStore** and needs to be used in **healthStore.exerciseSequenceHelper** mode.

#### Constant

**System capability:** SystemCapability.Health.HealthStore.Lite

**Since:** 6.1.1(24)

**Model restriction:** This API can be used only in the FA model.

| Name | Type | Description |
| --- | --- | --- |
| DATA_TYPE | [healthStore.DataType](https://developer.huawei.com/consumer/en/doc/harmonyos-references/health-api-healthstore-lite#datatype) | Workout record data type. |
