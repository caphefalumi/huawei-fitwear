# healthDataTypes (Health and Fitness Data Type Constants) (Lite)

This module provides constants of health and fitness data types.

**Since:** 6.1.1(24)

#### Modules to Import

```javascript
import healthStore from '@hms.health.store';
```

> **Note:** This module is a sub-module of **healthStore** and needs to be used in **healthStore.healthDataTypes** mode.

#### Constants

**System capability:** SystemCapability.Health.HealthStore.Lite

**Since:** 6.1.1(24)

**Model restriction:** This API can be used only in the FA model.
