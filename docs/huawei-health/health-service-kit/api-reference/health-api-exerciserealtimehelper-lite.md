# exerciseRealtimeHelper (Real-Time Fitness Data Type Constants) (Lite)

This module provides constants of real-time fitness data types.

**Since:** 6.1.1(24)

#### Modules to Import

```javascript
import healthStore  from '@hms.health.store';
```

> **Note:** This module is a sub-module of **healthStore** and needs to be used in **healthStore.exerciseRealtimeHelper** mode.

#### Constant

**System capability:** SystemCapability.Health.HealthStore.Lite

**Since:** 6.1.1(24)

**Model restriction:** This API can be used only in the FA model.

| Name | Type | Read-Only | Description |
| --- | --- | --- | --- |
| REALTIME_KEY_ACTIVE_TIME | string | Yes | Workout duration (duration during which the body is active), in seconds. Badminton, stair climbing, tennis, pickleball, and soccer are supported. |
| REALTIME_KEY_AEROBIC_TRAINING_STRESS | string | Yes | Level of training stimulation generated by a single workout on the body's aerobic system. A higher stimulation level indicates a larger value. Value range: [0.0, 5.0]. Badminton, stair climbing, tennis, pickleball, and soccer are supported. |
| REALTIME_KEY_ANAEROBIC_TRAINING_STRESS | string | Yes | Level of training stimulation generated by a single workout on the body's anaerobic system. A higher stimulation level indicates a larger value. Value range: [0.0, 5.0]. Badminton, stair climbing, tennis, pickleball, and soccer are supported. |
| REALTIME_KEY_HEART_RATE | string | Yes | Heart rate, in bpm. Badminton, stair climbing, tennis, pickleball, and soccer are supported. |
| REALTIME_KEY_DURATION | string | Yes | Workout duration, in seconds. Badminton, stair climbing, tennis, pickleball, and soccer are supported. |
| REALTIME_KEY_TOTAL_CALORIES | string | Yes | Total calories burned, in calories. Badminton, stair climbing, tennis, pickleball, and soccer are supported. |
| REALTIME_KEY_ACTIVE_CALORIE | string | Yes | Active calories, in calories. Badminton, stair climbing, tennis, pickleball, and soccer are supported. |
| REALTIME_KEY_AVG_SHOT_SPEED | string | Yes | Average swing speed, in km/h. Badminton is supported. |
| REALTIME_KEY_SHOTS | string | Yes | Number of swings. Badminton is supported. |
| REALTIME_KEY_MAX_CONTINUOUS_RALLY | string | Yes | Maximum number of consecutive rallies. Badminton, tennis, and pickleball are supported. |
| REALTIME_KEY_FOREHAND_STROKE | string | Yes | Number of forehand shots. Unit: integer. Badminton is supported. |
| REALTIME_KEY_BACKHAND_STROKE | string | Yes | Number of backhand shots. Unit: integer. Badminton is supported. |
| REALTIME_KEY_SMASH | string | Yes | Number of smashes. Unit: integer. Badminton is supported. |
| REALTIME_KEY_HIGH_CLEAR | string | Yes | Number of clears. Unit: integer. Badminton is supported. |
| REALTIME_KEY_MAX_SHOT_SPEED | string | Yes | Maximum swing speed, in km/h. Badminton is supported. |
| REALTIME_KEY_OVERHAND_STROKE | string | Yes | Number of overhead shots. Unit: integer. Badminton is supported. |
| REALTIME_KEY_UNDERHAND_STROKE | string | Yes | Number of underhand shots. Unit: integer. Badminton is supported. |
| REALTIME_KEY_TOTAL_STEPS | string | Yes | Step count. Unit: integer. Stair climbing is supported. |
| REALTIME_KEY_FLOORS | string | Yes | Number of floors. Stair climbing is supported. |
| REALTIME_KEY_AVG_FLOOR_SPEED | string | Yes | Stair climbing speed, in floors/minute. Stair climbing is supported. |
| REALTIME_KEY_FOREHAND | string | Yes | Number of forehand shots. Unit: integer. Tennis and pickleball are supported. |
| REALTIME_KEY_BACKHAND | string | Yes | Number of backhand shots. Unit: integer. Tennis and pickleball are supported. |
| REALTIME_KEY_SWING_TIMES | string | Yes | Number of swings. Unit: integer. Tennis and pickleball are supported. |
| REALTIME_KEY_GOALS_TIMES | string | Yes | Number of goals. Unit: integer. Soccer is supported. |
| REALTIME_KEY_ASSISTS_TIMES | string | Yes | Number of assists. Soccer is supported. |
