# Creating/Updating an Activity Record

#### Function

Creates or updates an activity record.

#### Scenario

Creates or updates an activity record, such as for running or rope jumping.

#### Restrictions

You can call this API to write the statistical data for data types described in the following table.

| Statistical Data Type | Statistical Type Name | Atomic Data Type |
| --- | --- | --- |
| Steps | com.huawei.continuous.steps.total | com.huawei.continuous.steps.delta |
| Distance | com.huawei.continuous.distance.total | com.huawei.continuous.distance.delta |
| Calories | com.huawei.continuous.calories.burnt.total | com.huawei.continuous.calories.burnt |
| Heart rate during workout | com.huawei.continuous.exercise_heart_rate.statistics | com.huawei.instantaneous.exercise_heart_rate |
| Step cadence | com.huawei.continuous.steps.rate.statistics | com.huawei.instantaneous.steps.rate |
| Sleep | com.huawei.continuous.sleep.statistics | com.huawei.continuous.sleep.fragment |
| Jump | com.huawei.continuous.jump.statistics | com.huawei.continuous.jump |

#### API Prototype

| **Protocol** | HTTPS PUT |
| --- | --- |
| **Direction** | App > Health Kit cloud |
| **URL** | https://health-api.cloud.huawei.com/healthkit/v1/activityRecords/{**activityRecordId**} |
| Data Format | Request: Content-Type: application/json Response: Content-Type: application/json |

#### Path Parameters

| Parameter | Type | Mandatory (M)/Optional (O) | Description |
| --- | --- | --- | --- |
| activityRecordId | String | M | ID of the activity record. The value must be the same as the request body ID and contains 1 to 1000 characters. |

#### Input Parameters

**Request Header**

| Parameter | Type | Mandatory (M)/Optional (O) | Description |
| --- | --- | --- | --- |
| Content-type | String | M | Value: **application/json; charset=UTF-8** |
| Authorization | String | M | For details, see [OAuth 2.0-based Authentication](https://developer.huawei.com/consumer/en/doc/development/HMSCore-Guides-V5/open-platform-oauth-0000001053629189-V5). NOTE: A space character must be added between **Bearer** and the value of **access_token**. |
| x-client-id | String | O | App ID allocated by HUAWEI Developers. The server can perform gray routing based on this parameter. It is recommended that this parameter be carried. |
| x-version | String | O | Software version number of the app calling the API, that is, the version number of the current client. The server can perform gray release based on this parameter. It is recommended that this parameter be carried. |
| x-caller-trace-id | String | O | Request tracing ID, which is used to connect the entire request chain between the service calling party and server. It is recommended that this parameter be carried. |

**Request Body**

| Parameter | Type | Mandatory (M)/Optional (O) | Description |
| --- | --- | --- | --- |
| appInfo | AppInfo | M | App information of the data collector. For details, see [AppInfo](https://developer.huawei.com/consumer/en/doc/development/HMSCore-References-V5/data-model-0000001054556973-V5#EN-US_TOPIC_0000001054556973__section982495714175). |
| id | String | M | Identifier generated by the client for an **ActivityRecord**. It is unique across all **ActivityRecord**s owned by the user. The value must be the same as that of **activityRecordId** as the path parameter and contains 1 to 1000 characters. |
| startTime | Long | M | Start time of the **ActivityRecord** (in milliseconds). The value must be a 13-digit integer timestamp, ranging from 2000-01-01 00:00:00 to 2099-12-31 23:59:59. **startTime** must be earlier than **endTime**. The duration specified by **startTime** and **endTime** must not exceed 5 days. |
| endTime | Long | M | End time of the **ActivityRecord** (in milliseconds). The value must be a 13-digit integer timestamp, ranging from 2000-01-01 00:00:00 to 2099-12-31 23:59:59. **endTime** must be later than **startTime**. The duration specified by **startTime** and **endTime** must not exceed 5 days. |
| activityType | Integer | O | [Activity type constant](https://developer.huawei.com/consumer/en/doc/development/HMSCore-Guides-V5/activity-types-0000001050071667-V5) value corresponding to the activity record. For example, running corresponds to 56. |
| activeTime | Long | O | Active time of the activity record. The unit is milliseconds. |
| activitySummary | ActivitySummary | O | Summary of the activity record. For details, see [ActivitySummary](https://developer.huawei.com/consumer/en/doc/development/HMSCore-References-V5/data-model-0000001054556973-V5#EN-US_TOPIC_0000001054556973__section1653018251396). |
| desc | String | O | Description of the activity record. Length range: 1 to 1000 characters |
| modifyTime | Long | O | The last time the **ActivityRecord** was modified. If **modifyTime** is specified when creating **activityRecords**, the passed **modifyTime** value will be returned when the UI returns the **activityRecords** information created by the user. |
| name | String | O | User-defined name of the **ActivityRecord**. Length range: 1 to 1000 characters |
| timeZone | String | O | Time zone information. Format: +0800. |
