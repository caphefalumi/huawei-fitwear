# Overview

All classes listed here are results for calling the Health Kit APIs. You can use these classes for the callback of the APIs.

#### Class Summary

| Name | Description |
| --- | --- |
| [ActivityRecordReply](https://developer.huawei.com/consumer/en/doc/development/HMSCore-References-V5/activityrecordreply-0000001050093245-V5) | Response class for reading the **ActivityRecord** result. |
| [ReadReply](https://developer.huawei.com/consumer/en/doc/development/HMSCore-References-V5/readreply-0000001050093471-V5) | Data reading response class. |
| [HealthKitAuthResult](https://developer.huawei.com/consumer/en/doc/development/HMSCore-References-V5/auth-result-0000001098318552-V5) | Result class of the sign-in authorization process. |
