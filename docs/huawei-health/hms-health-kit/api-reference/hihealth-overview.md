# Overview

A set of function classes of Health Kit, with the entry class being [HuaweiHiHealth](https://developer.huawei.com/consumer/en/doc/development/HMSCore-References-V5/huaweihihealth-0000001050091513-V5).

#### Class Summary

| Name | Description |
| --- | --- |
| [ActivityRecordsController](https://developer.huawei.com/consumer/en/doc/development/HMSCore-References-V5/activityrecordscontroller-0000001050091295-V5) | Provides methods to create and manage user activity records. |
| [AutoRecorderController](https://developer.huawei.com/consumer/en/doc/development/HMSCore-References-V5/autorecordercontroller-0000001050091345-V5) | Provides real-time data reading functions. |
| [ConsentsController](https://developer.huawei.com/consumer/en/doc/development/HMSCore-References-V5/consentscontroller-0000001060039068-V5) | Provides methods to view and revoke app permissions. |
| [DataController](https://developer.huawei.com/consumer/en/doc/development/HMSCore-References-V5/datacontroller-0000001050089472-V5) | Provides methods to add, delete, modify, and query the platform data. |
| [HiHealthActivities](https://developer.huawei.com/consumer/en/doc/development/HMSCore-References-V5/hihealthactivities-0000001050089540-V5) | Provides definitions of activity types. |
| [HiHealthOptions](https://developer.huawei.com/consumer/en/doc/development/HMSCore-References-V5/hihealthoptions_class-0000001050089546-V5) | Provides scope management functions. |
| [HiHealthStatusCodes](https://developer.huawei.com/consumer/en/doc/development/HMSCore-References-V5/hihealthstatuscodes-0000001050089560-V5) | Provides definitions of status codes. |
| [HuaweiHiHealth](https://developer.huawei.com/consumer/en/doc/development/HMSCore-References-V5/huaweihihealth-0000001050091513-V5) | Provides entry to APIs. |
