# Subscribing to Event Notifications

#### Function

Sends a notification for changes of a user event.

#### Scenario

Notifies the app of the user data changes when a user remokes a permission, an activity record updates, or the atomic data changes.

#### Restrictions

None.

#### API Prototype

| **Protocol** | HTTPS POST |
| --- | --- |
| **Direction** | Health Kit cloud > Non-Huawei cloud |
| **URL** | https://www.example.com/healthkit/notifications |
| Data Format | Request: Content-Type: application/json Response: Content-Type: application/json |

#### Input Parameters

**Request Header**

| Parameter | Type | Mandatory (M)/Optional (O) | Description |
| --- | --- | --- | --- |
| Content-type | String | M | Value: application/json; charset=UTF-8 |
| x-notification-signature | String | M | Signature of the event notification content. Signature format: HMAC-SHA256 with the subscriber Secret (**openId_eventType _eventTime**). NOTE: • The signature is generated using **Secret** and the HMAC SHA256 algorithm. • **Secret** can be accessed from the HUAWEI Developers service widget and needs to be decrypted using Base64. • The app can compare the signature generated by itself with the signature in the received message header to determine whether the received message is valid. |

**Request Body**

| Parameter | Type | Mandatory (M)/Optional (O) | Description |
| --- | --- | --- | --- |
| openId | String | M | User ID of the app. |
| eventTime | Long | M | Time when an event occurs. |
| eventType | String | M | Event type. |
| metaData | List<MetaData> | M | Metadata of an event extension. For details, please refer to the MetaData section of [Data Model](https://developer.huawei.com/consumer/en/doc/development/HMSCore-References-V5/data-model-0000001054556973-V5#EN-US_TOPIC_0000001054556973__section050215803917). |
