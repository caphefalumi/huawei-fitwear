# Data Model

#### ActivityRecord

| Parameter | Type | Mandatory (M)/Optional (O) | Description | Restrictions |
| --- | --- | --- | --- | --- |
| appInfo | AppInfo | M | **AppInfo** of the app that created the **ActivityRecord**. | For details, see [AppInfo](#EN-US_TOPIC_0000001054556973__section982495714175). |
| id | String | M | Identifier generated by the client for an **ActivityRecord**. It is unique across all **ActivityRecord**s owned by the user. | If no identifier is specified, it will be created from the start time and name. |
| modifyTime | Long | M | The last time the **ActivityRecord** was modified. The unit is milliseconds. | - |
| name | String | M | User-defined name of the **ActivityRecord**. For example, the name can be cycling on Sunday. | - |
| startTime | Long | M | Start time (inclusive) of the activity record. The unit is milliseconds. | - |
| activeTime | Long | O | Active time of the activity record. The unit is milliseconds. | The start/end time identifies the complete duration of the activity record. However, the active time of the activity record can be shorter. |
| activitySummary | ActivitySummary | O | Summary of the activity record. | For details, see [ActivitySummary](#EN-US_TOPIC_0000001054556973__section1653018251396). |
| activityType | Integer | O | Activity type corresponding to the activity record. | - |
| cursor | String | O | Identifier for the paginated query. It will be contained only when the query result is to be displayed on more than one page. | - |
| desc | String | O | Description of the activity record. | - |
| details | List<SampleSet> | O | Activity record details. | You can ignore this field. |
| endTime | Long | O | End time of the activity record. The unit is milliseconds. If it is not specified, the activity record is considered as still being in progress. | The end time must be later than the start time. |
| timeZone | String | O | Time zone information. | Format: +0800. |
| metadata | String | O | Extended metadata, which is a character string in JSON format. | - |

#### PaceSummary

| Parameter | Type | Mandatory (M)/Optional (O) | Description | Restrictions |
| --- | --- | --- | --- | --- |
| avgPace | Double | M | Average pace. | The unit is second/km. |
| bestPace | Double | M | Optimal pace. | The unit is second/km. |
| britishPaceMap | Map<String,Double> | O | Pace map in the imperial system. | Same as above, expect for the measurement system. |
| britishPartTimeMap | Map<String,Double> | O | Segmented time map in the imperial system. | Same as above, expect for the measurement system. |
| paceMap | Map<String,Double> | O | Pace map in the metric system. | This field indicates the pace information per kilometer. The unit is second/km. For example: "1.0":407.945 "2.0":473.98846 "2.170":473.98846 Note: For the last part of distance, if it is less than one kilometer, the pace will be converted in proportion and then be stored. |
| partTimeMap | Map<String,Double> | O | Segmented time map in the metric system. | Segmental data (key: kilometer; value: second) When the unit mile is used, the distance value is accurate to the fourth decimal place. Value is the time taken to cover the current distance. • 1.0:3.0 • 2.0:6.0 • 3.0:9.0 • 21.0975:7020.0 • 42.195:18000.0 Where, 21.0975 and 42.195 are the distances of the half Marathon and full Marathon, respectively. Except for these two types of race, the first decimal place is 0. |

#### DataCollector

| Parameter | Type | Mandatory (M)/Optional (O) | Description |
| --- | --- | --- | --- |
| appInfo | AppInfo | M | App information of the data collector. For details, see [AppInfo](#EN-US_TOPIC_0000001054556973__section982495714175). |
| collectorDataType | DataType | M | Data type definition. For details, see [DataType](#EN-US_TOPIC_0000001054556973__section16473950171714). |
| collectorType | String | M | Type of the data collector as a constant. The value can be: • **derived**: derived data type • **raw**: raw data type |
| collectorId | String | O | Unique identifier of the data collector. This field is generated based on the parameters in the request and must meet the following requirements: collectorType:collectorDataType.name: appInfo.appPackageName:deviceInfo.manufacturer: deviceInfo.modelNum:deviceInfo.uniqueId:collectorName When setting this parameter, make sure that its value is the same as the related fields in the request body. |
| collectorName | String | O | Internal identifier. The name is used to identify a data collector created for a certain data type by the user. |
| deviceInfo | DeviceInfo | O | Description of the hardware device that integrates various sensors, such as a watch, a band, or any other wearable devices. For details, see [DeviceInfo](#EN-US_TOPIC_0000001054556973__section135613218188). |
| name | String | O | Data collector's name to display in your app. |
| lastUpdateTime | Long | O | Last data update time, when the sampling data is uploaded to or deleted from the data collector. |

#### DataType

| Parameter | Type | Mandatory (M)/Optional (O) | Description | Restrictions |
| --- | --- | --- | --- | --- |
| field | List<DataTypeField> | M | A dimension of the data type. | For details, see [DataTypeField](#EN-US_TOPIC_0000001054556973__section1220315416170). NOTE: • For public data types, this field is written by the Health platform. • For customized data types, provide field values. |
| name | String | M | Unique, namespaced name of the data type. Length range: 1 to 300 characters | Huawei provides a group of shared, visible health data types ([public data types](https://developer.huawei.com/consumer/en/doc/development/HMSCore-Guides-V5/public-dt-0000001050069714-V5)) starting with com.huawei. as the namespace. Customized data types are also supported, but the name of a customized data type cannot start with com.huawei. |
