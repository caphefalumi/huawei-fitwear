# Measuring the Step Count of the Day

This section provides an example of how to obtain the user's step count of the current day via the server API of Health Kit. The daily step count is stored using **SampleSet**. You can send a POST request to query the **com.huawei.continuous.steps.delta** data type to obtain the user's step count over a specified period of time.

**Preset data**

You can use the Health app to preset data for debugging.

**Read the user's step count**

The step count over a specified period of time can be obtained by calling the RESTful API.

**HTTP request**. For details, see [Grouping Sampling Data](https://developer.huawei.com/consumer/en/doc/development/HMSCore-References-V5/sampleset_polymerize-0000001050114864-V5#EN-US_TOPIC_0000001053248379__section984123664716).

```cpp
POST
https://health-api.cloud.huawei.com/healthkit/v1/sampleSet:polymerize
```

**Request example**

```cpp
POST 
https://health-api.cloud.huawei.com/healthkit/v1/sampleSet:polymerize
```

**Request body**

Suggestion:

- In the request body, **startTime** and **endTime** indicate the millisecond timestamp corresponding to the start time (00:00:00 to 23:59:59) and end time (00:00:00 to 23:59:59) of a day, respectively.
- **groupByTime** indicates that data is grouped by day.
- **timeZone** indicates the local time zone.

```cpp
Content-Type: application/json
Authorization: Bearer ***
x-client-id: ***
x-version: ***
x-caller-trace-id: ***
{
 "polymerizeWith": [
  {
   "dataTypeName": "com.huawei.continuous.steps.delta"  
  }
 ],
 "endTime": 1590422399000,
 "startTime": 1590336000000,
 "groupByTime": {
     "groupPeriod": {
         "unit": "day",
         "value": 1,
         "timeZone": "+0800"
    }
  }
}
```
