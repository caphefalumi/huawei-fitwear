# SDK Data Security

#### How Does the SDK Work?

The extended Health Kit capabilities SDK needs to be integrated into your app during app packaging. It starts when the app is launched and stops as soon as the app is closed, without performing any operations in the background.

#### What Permissions Are Required for Using the SDK?

**SDK Permissions**

Your app integrating the extended Health Kit capabilities SDK does not need to apply for additional permissions from the phone system.

**HUAWEI Health App Permissions**

The API call of the extended Health Kit capabilities SDK will ultimately be processed by the HUAWEI Health app. The app must be granted with permissions to call the various APIs. The statement of the related permissions should be provided in the privacy statement of the developer.

- Location permission: To record the trajectory data or link a BLE device, the HUAWEI Health app needs to obtain the location permission from the phone.
- Permission to access the pedometer sensor: To record the pedometer data, the HUAWEI Health app needs to obtain the pedometer access permission from the phone.
- Bluetooth permission: To call the BLE device API, the HUAWEI Health app needs to obtain the Bluetooth permission.

#### What Data Does the SDK Collect

The extended Health Kit capabilities SDK will never proactively collect or process users' personal data. It works only at the request of third-party apps. After user authorization, your apps can read and write data with corresponding permissions through the SDK. For details about the supported data types and permissions, see [Scope](https://developer.huawei.com/consumer/en/doc/development/HMSCore-Guides-V5/scope-0000001053805684-V5) in the appendix.

#### How Does the SDK Protect Your Data?

Currently, data written via the extended Health Kit capabilities SDK will not be uploaded to the cloud. Only the weight (body fat scale) data can be written and read. Other data can only be read.

**Data Access Control**

- An app must pass the signature authentication to call the SDK APIs.
- An app requires sign-in and data access permissions, before it can access the related data via the SDK APIs.

**Local Data Encryption**

On Huawei phones running EMUI 8.1 or a later version, a hierarchical data protection mechanism provided by the system hardware takes effect on the fitness and health data, for security and reliability of local data.
