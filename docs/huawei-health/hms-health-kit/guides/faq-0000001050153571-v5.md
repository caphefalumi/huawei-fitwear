# FAQ

#### What should I do if errors occur when requesting for user authorization?

- When using the HUAWEI Health app for the first time, make sure to agree to the privacy statement, and check whether the app is up to date.
- Make sure that the app ID, package name, and signature of the third-party app on the phone are the same as those provided when [applying for the HUAWEI ID service](https://developer.huawei.com/consumer/en/doc/development/HMSCore-Guides-V5/apply-id-0000001050069756-V5).
- Make sure that you have created a signed app. That is, you have created the app by going to **Build** > **Generate Signed Bundle...** in Android Studio.
- Make sure that you have applied for the data permissions involved in user authorization from HUAWEI Developers and the application has been approved. For details, please refer to [Applying for Health Kit](https://developer.huawei.com/consumer/en/doc/development/HMSCore-Guides-V5/apply-kitservice-0000001071254802-V5).
- When calling the **signIn** method to pass the read and write permissions, check whether the read and write permission names are correct and whether the permission names are required.
- Make sure that function development has been completed, by referring to [Signing In and Applying for Permissions](https://developer.huawei.com/consumer/en/doc/development/HMSCore-Guides-V5/requesting-user-authorization-0000001071733944-V5).

#### Why is an empty response body returned when calling the data read/query API?

If there is no such data, an empty response body will be returned. This will also happen if the user has not authorized the app to obtain the related data types.

If you still have concerns, please contact the Huawei contact person.

#### Can the users' fitness and health data be read when the device screen is locked?

No. When the device screen is locked, apps are not allowed to read data from the HUAWEI Health app.

#### Why are the real-time heart rate and RRI data not continuous?

Wearable devices report data to the HUAWEI Health app at intervals. When connecting to a watch via the HUAWEI Health app, the real-time heart rate data is obtained once per second. The data is obtained once every 5 seconds via the heart rate API.

#### Why is HiHealthError.ERR_SCOPE_EXCEPTION returned?

This result code will be returned if you have not applied for the required data permissions for Health Kit at the HUAWEI Developers website, or the data permissions have been revoked.

#### Why can't deleteSample() delete data?

Your app can delete only the weight data that it has written to the HUAWEI Health app.
