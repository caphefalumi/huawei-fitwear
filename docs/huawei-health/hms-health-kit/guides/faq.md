# FAQs

Face other challenges or don't find your issue below? Please join discussions on [Stack Overflow](https://stackoverflow.com/questions/tagged/huawei-mobile-services?tab=Newest).

#### Common FAQs Regarding SDK Integration

## The query results do not match what has been written, after writing multiple data with overlapping time intervals. Why is that?

For data with overlapping time intervals, the data layer will process them using certain service logic. If there are considerable discrepancies between the query results and written data, please contact the Huawei contact person for assistance.

## Result code 50005 is returned to indicate an unknown authentication error when calling an API. What should I do?

- Ensure that the application for Health Kit data has been approved. Otherwise, your app will not able to access the user data even the user has granted the permission.
- The data that an app can access must be within the range of data involved in the data approval for Health Kit and within the scope granted to the app.
- Ensure that the scopes added at step 1 in [Signing In and Applying for Permissions](https://developer.huawei.com/consumer/en/doc/development/HMSCore-Guides-V5/add-permissions-0000001050069726-V5) are the ones requested for your app.
- The HMS Core (APK) caches the scope permission information and retains the information for 24 hours. This issue may be caused by the cache.On your phone, open **Settings**, search for and access **Apps**, then clear the cache and data of HMS Core.
- Go to **Settings **> **HUAWEI ID** >** Privacy center** > **Control account access** to cancel the app authorization. Then re-open the app, sign in to your HUAWEI ID, and apply for the scopes.
- If the issue persists, please contact the Huawei contact person.

## Do different third-party apps integrated with the Health Kit share the same data? Will CRUD operations on one app affect the rest of the apps?

- Data query on the device: Data generated by different apps is isolated and stored on the device, and converged computing will be performed on the data. Third-party apps can query their own data and converged data.
- Data addition, deletion, and modification on the device: Third-party apps can perform such operations only on their own data, without affecting data of other apps. However, the operations will affect the convergent data.
- CRUD operations on the cloud: Data generated by different third-party apps is automatically synced to the Health Kit server for isolated storage on a scheduled basis. The server end performs reduction operation on the data to generate converged data for the account. Different device-side apps can then query the converged data after being authorized by the user.
- The data repositories of the Health Kit device and cloud ends are data processors, and the third-party apps based on Health Kit are data controllers.

## What should I do if result code 2002 is returned when calling the HuaweiIdAuthService.silentSignIn() method during login and permission application?

Refer to Common Error Codes of Account Kit for troubleshooting. This result code indicates that the HUAWEI ID is not authorized or fails to be authorized. You can call the **HuaweiIdAuthService.getSignInIntent()** API to perform authorization again. For details about the code, see [Signing In and Applying for Permissions](https://developer.huawei.com/consumer/en/doc/development/HMSCore-Guides-V5/add-permissions-0000001050069726-V5).

## What should I do if the authorization page cannot be displayed and result code 907135000 is displayed after logging in to a HUAWEI ID?

This result code indicates that there are errors in the passed parameters. The possible cause is that Appid is not configured in the manifest file. Modify the related information by referring to [Adding the App ID Information](https://developer.huawei.com/consumer/en/doc/development/HMSCore-Guides-V5/integrating-sdk-0000001050069724-V5#EN-US_TOPIC_0000001050986519__section21957147910). Note that **com.huawei.hms.client.appid** is the keyword used by the HMS framework to identify **AppId**. Do not change it to the package name of your app.

## What should I do if calling setting.getHealthAppAuthorization() in SDK 5.0.5.300 or an earlier version returns Exception: com.huawei.hms.common.ApiException: 50011: Attempt to invoke virtual method 'int java.lang.String.length()' on a null object reference?

The [country/region](https://developer.huawei.com/consumer/en/doc/development/HMSCore-Guides-V5/countries-regions-0000001058740695-V5) of your HUAWEI ID is not supported by Health Kit. Register a new HUAWEI ID when necessary. If the issue persists, keep detailed logs (do not filter the logs so technical support engineers can have the full data for troubleshooting) and contact Huawei technical support.

## Calling the DataController.read, readDailySummation, readTodaySummation, or ActivityRecordsController.getActivityRecord API does not return any data from the Health app. What should I do?

Make sure the data you want to obtain is displayed in the Health app. Then do the following:

1. Make sure your app has the permission to access the data. The result code 50005 will be returned if your app does not have the permission.

2. Ensure that your app's access process strictly complies with the instructions in [Signing In and Applying for Permissions](https://developer.huawei.com/consumer/en/doc/development/HMSCore-Guides-V5/add-permissions-0000001050069726-V5), especially the instructions in step 2.

3. It is recommended that you update the Health app to the latest version.

- Huawei phone: 11.0.0.512 or later
- Non-Huawei Android phone: 11.0.1.512 or later

4. Make sure the HMS Core version is 5.0.3.300 or later.

5. Check the following privacy settings in the Health app:

- Sync personal info to cloud
- Sync fitness data to cloud
- Sync health data to cloud

Do the following to ensure that the desired data is synced to the Health server:

In Health, go to **Me** > **Settings**, and touch **SYNC** next to **Sync data manually**.

6. After you complete step 5, make sure Health Kit has been authorized to read data in the Health app:

- Open the Health app, go to **Me** > **Privacy management** > **Link Huawei Health Kit**.
- If Health Kit is not linked, go to step 2 to troubleshoot. If the issue persists, save the detailed logs and contact the Huawei technical support for assistance. Do not filter the logs for fault locating and analysis.

#### Common FAQs Regarding RESTful Integration

## What should I do if the "Invalid Credentials" message is returned when calling an API?

This message will be returned if the API is being called with an invalid token. Perform the following to troubleshoot:

- Verify that the authorization code mode has been used to request the token. For details, see [Authorization Code](https://developer.huawei.com/consumer/en/doc/development/HMSCore-Guides-V5/open-platform-oauth-0000001053629189-V5#EN-US_TOPIC_0000001053629189__section1022911426469) in OAuth 2.0-based Authentication.
- Verify that you have strictly followed the standard procedure when applying for the token.
- Check whether the token has expired.

## In which cases will the refresh_token expire and how to handle the situation?

- The refresh_token is not permanently valid. Currently, the refresh token is valid for six months. The validity period is not directly returned in the API and this may change in the future. When using AT to replace RT, saving the new RT can effectively reduce the change that the RT goes invalid.
- The refresh_token expires immediately if any of the following situations happens: The password is changed.
- The user's account has been frozen.
- The user's account has been changed or deleted.
- The user's account is deregistered.
- The device is deleted automatically due to the number limit or manually by the user.
- The user is logged out from the phone client APK (device).
- The user is logged out from the current browser.
- The user is logged out from all browsers.

If the refresh_token expires, when the access_token is updated, the result code 1203 is returned. The sub-code is 11205 or 31204. For details, see [Errors and Troubleshooting](https://developer.huawei.com/consumer/en/doc/HMSCore-Guides-V5/open-platform-error-0000001053869182-V5). You must mark the refresh_token as expired. When the user logs in next time, authentication and authorization need to be performed again.

## What should I do if the "Insufficient Permission: Request had insufficient authentication scopes." message is returned when calling an API?

Related permissions are required for reading and writing data in Health Kit. This message will be returned if the scope permissions are insufficient to support the operation. Make sure that the required permissions have been properly authorized.

The possible causes are as follows:

- The API permissions have not been correctly applied for. Please refer to [Health Kit Scope List](https://developer.huawei.com/consumer/en/doc/development/HMSCore-Guides-V5/scope-list-0000001055419280-V5#EN-US_TOPIC_0000001055419280__section1078716412914) to apply for the required permissions. For example, to create a data source with the data type of **com.huawei.instantaneous.steps.rate**, you need to obtain the write permission. Make sure that your app has been authorized with either or both of the following permissions:"https://www.huawei.com/healthkit/step.write"

- "https://www.huawei.com/healthkit/step.both"

- The user has not granted the authorization. You need to add related processing to ask for user authorization whenever needed.

## Why is a "400 Bad Request invalidArgument" message returned when the configurations are correct?

This message indicates that the parameters in the request are incorrect. If the URL contains user-specified request parameters, check whether the input parameters meet the parameter specifications. If the request body exists, check whether the format and type of the corresponding parameters meet the parameter requirements.

## What should I do if an "Application package name (xxx) provided by un-trusted source." message is returned when creating data?

The app name you are using has not yet been registered with HUAWEI Developers. Please go to the HUAWEI Developers website and submit a registration request. This issue should be resolved after your request is approved.

## What should I do if an empty body is returned after calling the authorized data query API when there is data on the Health app?

- Check whether the API fails to be executed and check the [result code](https://developer.huawei.com/consumer/en/doc/development/HMSCore-Guides-V5/hihealthstatuscodes-0000001059858802-V5#EN-US_TOPIC_0000001059858802__section743111615530).
- Make sure the version of the Health app in use is:Huawei phone: 11.0.0.512 or later
- Non-Huawei Android phone: 11.0.1.512 or later
- iPhone: 8.0.44.301 or later

- Call the API to check whether the Health app has been authorized to open data to Health Kit. If it has not been authorized, instruct the user to grant the authorization.Android user: Open Health, go to **Me** > **Settings** > **Data sharing** > **Health Kit**, and grant the authorization.
- iPhone user: Open Health, go to **Me** > **Third party services** > **HUAWEI Health Kit**, and touch **LINK**.

- Open the Health app, and go to **Me** > **Settings**. Touch **Sync data manually** to sync data to the cloud and also enable **Auto-sync data**.
- Ensure that the phone has an Internet connection, and the app is allowed to use the mobile data or Wi-Fi network. A phone manager or assistant app on the phone may restrict the app from accessing the Internet.
- Check whether the user has agreed to the user agreement. Go to **Me** > **Settings** > **Privacy settings** > **Huawei Health Notice**, and touch **AGREE**.
- Open the Health app, go to **Me** > **Settings** > **Privacy settings**, and turn on all switches under **Data management** to enable data syncing to the cloud.
- If the issue persists, please contact the Huawei contact person.
