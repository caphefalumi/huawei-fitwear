# Bluetooth Sample Code

You can obtain the FTMP profile sample code and the related description from the development suite.

The sample code implements the core functions of the FTMP profile and is decoupled from the specific protocol stack. The fitness machine manufacturer needs to perform adaptation and integration based on the Bluetooth module in use. The provisioning of the sample code helps accelerate the development based on the Bluetooth module protocols, and ensure the protocol compliance consistency.
