# Advantages

#### A Series of Open APIs, a Wide Range of Data Types, and Well-formed Standards

- Support for the storage and acquisition of multiple data types, covering mainstream fitness and health scenarios.
- Support for customized, unlimited data types.

#### Enhanced Data Accuracy

- Data can be sourced from Huawei wearable devices, guaranteeing the high quality.

#### Complying with Strict Privacy Protection Standards

User-level keys and chip-level encryption are used to ensure device and cloud data storage security.

- Data security managementHierarchical management of data by category
- In-depth synergy for security between the device, phone, and cloud
- Isolated management of app permissions
- Blocklist for malicious apps

- User authorization managementSupport for proactive authorization and authorization revoking
- Separate controls for read and write permissions
- Access controls for subdivided data types

- Privacy compliance managementCompliance with privacy laws and regulations across the globe, including the EU GDPR, for privacy management.
- Full lifecycle management for personal data by observing the GAPP and other best practices in the industry
