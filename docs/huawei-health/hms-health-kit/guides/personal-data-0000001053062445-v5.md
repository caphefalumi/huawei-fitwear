# Personal Data Processing Information

Last modified: December 27, 2020

Huawei is a data processor, but not a data controller. The purpose and method of using data are determined by users.

In personal data processing of the extended Health Kit capabilities, Huawei serves as the end user data processor, and you (the developer) serve as the end user data controller. For appropriate and legal processing of personal data, the following are provided:

- List of personal data processed by Huawei
- Guidance for you to help the end user control personal data

#### List of Personal Data Processed by Huawei

| Personal Data | Processing Purpose | Retention Period |
| --- | --- | --- |
| Personal information: gender, date of birth, height, and weight | Extended Health Kit capabilities provide a platform for users to store and share their data. They do not proactively process any user data. All data display and fitness and health services are provided by you. | After a user deletes their HUAWEI ID, their personal data will be deleted. |
| Fitness data: step count, distance, calories burnt, and medium- and high-intensity; walking, cycling, and running records; real-time heart rate, RRI, and workout data |  |  |
| Health data: weight, body fat, heart rate, sleep data, blood oxygen data, and stress data |  |  |
| Device ID of the data collector | The device ID is used to identify the source of the data. |  |

#### Guidance for You to Help the End User Control Personal Data

- How to Clear the End User's Personal Data After a user logs in to your app that has integrated extended Health Kit capabilities and authorizes the related permissions, you can call [deleteSample](https://developer.huawei.com/consumer/en/doc/development/HMSCore-Guides-V5/deleting-data-0000001050163993-V5) to delete the user data written by your app to the HUAWEI Health app.
- The user can delete their personal data by deleting their HUAWEI ID. All personal data under their HUAWEI ID will be deleted.

- How to Export the End User's Personal Data After integrating extended Health Kit capabilities into your app, you can obtain user data through the data access API, so as to provide the data export service for users. For details, see [execQuery](https://developer.huawei.com/consumer/en/doc/development/HMSCore-Guides-V5/querying-dailyactivity-0000001053253403-V5#EN-US_TOPIC_0000001090410690__section1269593195415).
