# Getting Started

#### Quick Tutorial

Before developing your app, you can use the [sample code](https://developer.huawei.com/consumer/en/doc/development/HMSCore-Examples-V5/healthextention-samplecode-0000001051089626-V5) to view what your app will look like after integrating extended Health Kit capabilities.

#### Development Environment

**Android Platform**

- Android Studio version: 3.*X* or later
- JDK version: 1.8.211 or later
- SDK and Gradle: minSdkVersion 24
- targetSdkVersion: 29
- compileSdkVersion: 29
- Gradle version: 4.6 or later

If you need to use multiple HMS Core kits, use the latest versions required for these kits.

- Test device: A Huawei phone that runs Android 6.0 or later and has HUAWEI Health app installed

#### Development Process

Follow the steps in the following process when you develop an app.

| **No.** | Step | Description |
| --- | --- | --- |
| 1 | [Register a HUAWEI ID and apply for the HUAWEI ID service](https://developer.huawei.com/consumer/en/doc/development/HMSCore-Guides/apply-id-0000001050069756) | The process is the same as that of the basic Health Kit capabilities. Skip this app if you have done so for the basic capabilities. |
| 2 | [Apply for Health Kit](https://developer.huawei.com/consumer/en/doc/development/HMSCore-Guides-V5/apply-kitservice-0000001071254802-V5) | Enable the permissions to read and write fitness and health data. • Log in to HUAWEI Developers, go to **Console** > **Health Kit**, select the required data permissions, and submit your application. • Send the enterprise introduction information and data application reasons [as required](https://developer.huawei.com/consumer/en/doc/development/HMSCore-Guides-V5/apply-kitservice-0000001071254802-V5#EN-US_TOPIC_0000001090570632__li5971625861) to hihealth@huawei.com. • Wait while your application is under approval. NOTE: The commissioning procedure won't be successful unless you have obtained the related permissions. If the permission verification fails, you won't be able to access the related functions of extended Health Kit capabilities. |
| 3 | [Integrate the HMS Core SDK](https://developer.huawei.com/consumer/en/doc/development/HMSCore-Guides-V5/integrating-sdk-0000001050060847-V5) | Integrate the extended Health Kit capabilities SDK into your app. |
| 4 | [Configure obfuscation scripts](https://developer.huawei.com/consumer/en/doc/development/HMSCore-Guides-V5/config-obfuscation-scripts-0000001071222399-V5) | Before building the APK, configure the obfuscation configuration file to prevent the HMS Core SDK from being obfuscated. |
| 5 | [Develop your app](https://developer.huawei.com/consumer/en/doc/development/HMSCore-Guides-V5/requesting-user-authorization-0000001071733944-V5) | Use Android Studio to develop your app and follow instructions in this guide to integrate extended Health Kit capabilities into your app. |
| 6 | [Commissioning and Verification](https://developer.huawei.com/consumer/en/doc/development/HMSCore-Guides-V5/commissioning-verification-0000001050159257-V5) | Execute the test cases. |
| 7 | [Perform pre-release check](https://developer.huawei.com/consumer/en/doc/development/HMSCore-Guides/pre-release-check-0000001050714942) | The process is the same as that of the basic Health Kit capabilities. |
| 8 | [Release your app](https://developer.huawei.com/consumer/en/doc/development/HMSCore-Guides/app-release-0000001051074910) | The process is the same as that of the basic Health Kit capabilities. |
