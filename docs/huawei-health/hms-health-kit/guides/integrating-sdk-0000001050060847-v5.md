# Integrating the HMS Core SDK

Android Studio development environment V3.3.2 or later is recommended.

#### Configuring the Maven Repository Address

- Open the build.gradle file in the root directory of your Android Studio project.Figure 1 **Opening the **build.gradle** file**
- Go to buildscript > repositories and add the Maven repository address.
```cpp
maven {url 'https://developer.huawei.com/repo/'}
```
 Figure 2 **Configuring the Maven repository**
- Go to allprojects > repositories and add the Maven repository address.
```cpp
maven {url 'https://developer.huawei.com/repo/'}
```
 Figure 3 **Configuring the Maven repository** > **Note:** The Maven repository address cannot be accessed from a browser. It can only be configured in the IDE. If there are multiple Maven repositories, add the Maven repository address of Huawei to the end of the file.

#### Adding Build Dependencies

- Open the build.gradle file in the app directory.Figure 4 **Opening the **build.gradle** file in the **app** directory**
- Add build dependencies in the dependencies section.
```cpp
implementation 'com.huawei.hihealth:hihealthkit:{version}'
```
 Figure 5 **Adding build dependencies > **Note:** Replace *{version}* with the actual SDK version number. For version numbers, please refer to [Version Change History](https://developer.huawei.com/consumer/en/doc/development/HMSCore-Guides-V5/version-change-history-0000001053214729-V5).
- Open the modified **build.gradle** file again. You will find a **Sync Now** link in the upper right corner of the page. Click **Sync Now** and wait until synchronization is complete.**Figure 6 **Clicking **Sync Now** to sync your project > **Note:** If an error occurs, check the network connection and the configurations in the **build.gradle** file.
