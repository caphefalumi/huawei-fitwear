# Getting Started

Follow the steps in the following process when you develop an app.

| No. | Step | Description |
| --- | --- | --- |
| 1 | [Registering a HUAWEI ID and Applying for the HUAWEI ID Service](https://developer.huawei.com/consumer/en/doc/development/HMSCore-Guides-V5/apply-id-0000001050747587-V5) | Register as a developer and complete identity verification, and apply for the HUAWEI ID service. Then sign the agreement and access the app information filling page. |
| 2 | [Applying for Health Kit](https://developer.huawei.com/consumer/en/doc/development/HMSCore-Guides-V5/apply-kitservice-0000001050707556-V5) | Apply for the Health Kit service, select the product type, and enable the read and write permissions for the corresponding data. |
| 3 | [Checking Permissions and Obtaining Authorization](https://developer.huawei.com/consumer/en/doc/development/HMSCore-Guides-V5/get-access-token-0000001050322650-V5) | Obtain the access token after your app integrated with Account Kit is authorized by the user. |
| 4 | [Developing your app](https://developer.huawei.com/consumer/en/doc/development/HMSCore-Guides-V5/use-restful-api-0000001050071697-V5) | Following the guide, integrate Health Kit basic capabilities to the cloud-side app and develop desired functions based on service needs. |
