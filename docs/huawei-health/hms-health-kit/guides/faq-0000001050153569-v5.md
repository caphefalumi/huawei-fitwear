# FAQs Related to Fitness Machine Access

#### What should I do if the bluetooth connection won't set up?

Power on the Bluetooth fitness machine and make sure that Bluetooth advertising starts. Note that some fitness machines may require activation by pressing a button before Bluetooth advertising can start.

#### Why does the app not show the real-time workout data screen after the Bluetooth module successfully sends the device status notification?

In addition to checking the device status, the app also checks whether Treadmill Data is received. The real-time workout data screen will only be displayed when all required data has been received.

#### Must the unlock code be supported?

Yes. For security reasons, the unlock code must be supported. This prevents a fitness machine from being connected to someone else's phone when it is being used. If this is the case, that someone else will be able to control the machine, such as adjust the treadmill speed, leading to possible safety issues.

#### What does the app indicate that the workout has paused when the Bluetooth module does not report a pause event?

The app checks whether the Treadmill Data is received in a timely manner. If there is no Treadmill Data within the past 2 seconds, the app will determine that the fitness machine is paused. It is also possible that the treadmill has not reported Treadmill Data to the app for an extended period of time.

#### Must the NFC label be attached to the fitness machine?

Yes. To provide users with a convenient connection experience, an NFC label must be attached for users to establish a connection with a single tap.
