# Registering a HUAWEI ID and Applying for the HUAWEI ID Service

- Register as a developer and complete identity verification. For detailed operations, see [HUAWEI ID Registration](https://developer.huawei.com/consumer/en/doc/start/registration-and-verification-0000001053628148).
- Sign in to the [HUAWEI Developers](https://developer.huawei.com/consumer/en) website and click **Console**.

- Click **HUAWEI ID**. > **Note:** If the **HUAWEI ID** card can't be found, click **Customize console** in the upper right corner to add it.

- Click **Apply for HUAWEI ID**, agree to the agreement, and the screen for entering the product information is displayed. 
| **Item** | **Description** |
| --- | --- |
| Product type | • Select **Mobile app** for the client development. • Select **Server app** for server interconnection. |
| Access method (applicable only for Chinese mainland) | • For a mobile app, the default value is **SDK access**. If the server connection is required, select **JS-SDK access** as well. • For a web app, the default value is **JS-SDK access**. You do not need to select it. |
| Product | • If the product has been created, select the product from the product list.If the product has not been created, click **Create Product**. NOTICE: The app information you've configured when you created the product, such as app name and logo, will be displayed to users and cannot be modified. • After the product is successfully created, the app ID and secret information will be generated. Such information uniquely identifies an app. |
| Redirect URL | This parameter is mandatory for web apps and is provided by your technical personnel. You can change it in the future if necessary. NOTE: The value must be a valid URL starting with http(s) and contains up to 255 bytes. The URL cannot end with a slash (/), contain any question mark (?), or use the **get** parameter. An IP address and a port number can be included in the URL. The full path must be matched and there must be only one callback address. |
| App access URL | This parameter is mandatory for web apps. The URL is the egress IP address for third-party service. Multiple URLs are allowed. The value of this parameter is provided by your technical personnel. You can change it in the future if necessary. |
| Package name | Enter the [package name of the app](https://developer.huawei.com/consumer/en/doc/development/HMSCore-Guides-V5/package-name-0000001059578777-V5), for example, "com.health.demoanna". The value must be the same as the APK package name and cannot be changed once entered. CAUTION: If [customized data types](https://developer.huawei.com/consumer/en/doc/development/HMSCore-Guides-V5/customized-dt-0000001050069716-V5) are to be used, do not specify a package name that starts with com.huawei. |
| SHA256 certificate fingerprint | Enter the [signing certificate fingerprint](https://developer.huawei.com/consumer/en/doc/development/HMSCore-Guides-V5/signing-fingerprint-0000001059050363-V5). A signing certificate fingerprint is used to authenticate an app that attempts to call HMS Core (APK) through the HMS Core SDK. |

- Click **Submit** to submit your HUAWEI ID service application.
