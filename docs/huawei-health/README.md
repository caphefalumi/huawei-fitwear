# Huawei Health Developer Documentation

Official Huawei Developer documentation for health, workout, activity rings, and wearable biometric integration across HarmonyOS, Android, iOS, and Cloud REST APIs:

1. **HarmonyOS Health Service Kit (`health-service-kit/`)**: 88 docs (70 Guides, 18 API References) — Phone/Tablet & Wearable health store (`healthStore`), workout linkage (`healthService`), three-ring activity data, workout records, sleep/health sequences, and sample points (HR, SpO2, HRV, stress, body temperature, blood pressure, weight).
2. **HMS Core Health Kit (`hms-health-kit/`)**: 238 docs (108 Guides, 130 API References) — Android SDK & Cloud REST APIs for HUAWEI Health data openness, `DataController`, `AutoRecorderController`, `ActivityRecordsController`, `HealthRecordController`, `SettingController`, and `BleController`.
3. **Huawei Health Industry Wearable SDK (`health-industry-sdk/`)**: 494 docs — Direct wearable BLE pairing/connection, real-time sensor streaming (HR, ACC, GYRO, PPG, RRI, HRV), workout linkage, device control, and P2P messaging across HarmonyOS 5+ (100), HarmonyOS 3.1/4.0 (82), Android (210), iOS (87), and General/Appendix (15).

- **Total Documents**: 820
