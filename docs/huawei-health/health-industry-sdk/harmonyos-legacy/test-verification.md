# Debugging and Verification

You need to perform functional verification testing based on the following test cases.

| Test Case | Prerequisite | Step | Expected Result |
| --- | --- | --- | --- |
| Obtaining the correct certificate path for authentication | • The industry app has been installed on the smart watch. • The authentication certificate has been obtained and saved to the correct path. • The smart watch is connected to the Internet. | • Call the app authentication API for authentication. | For step 1, the authentication is successful, and result code **0** is returned. |
| Registering a listener for the server connection status | • The industry app has been installed on the smart watch. | • Call the API for listening to the server connection status. | For step 1, the registration is successful, and result code **0** is returned. If a service is killed in the background, the relevant result code is returned. |
| Obtaining the API level | • The industry app has been installed on the smart watch. | • Call the API for obtaining the API level. | For step 1, the API level of the server is returned. |
| Subscribing to the workout status | • The industry app has been installed on the smart watch. • The industry app has been authenticated. | • Call the API for subscribing to the workout status. • Wear the watch and start an indoor walk workout. | For step 1, the subscription is successful, and result code **0** is returned. For step 2, the industry app receives the workout status code **15** from the device. |
| Subscribing to the sleep status | • The industry app has been installed on the smart watch. • The industry app has been authenticated. | • Call the API for subscribing to the sleep status. • Change the sleep status. | For step 1, the subscription is successful, and result code **0** is returned. For step 2, the corresponding sleep status is reported. |
| Querying sleep data | • The industry app has been installed on the smart watch. • The industry app has been authenticated. | • Take a nap, which lasts more than 30 minutes and less than 2 hours. • Call the API for querying sleep data. • Sleep at night for more than 2 hours. • Call the API for querying sleep data. | For step 2, the corresponding nap data is returned. For step 4, the corresponding nighttime sleep and nap data is returned. |
| Subscribing to daily activity data | • The industry app has been installed on the smart watch. • The industry app has been authenticated. | • Call the API for subscribing to daily activity data. • Perform daily activities, such as walking and stair climbing. | For step 1, the subscription is successful, and result code **0** is returned. For step 2, the corresponding daily activity data is reported. |
| Querying daily activity data | • The industry app has been installed on the smart watch. • The industry app has been authenticated. | • Call the API for querying daily activity data. | For step 1, the query is successful and daily activity data is returned. |
| Subscribing to heart rate data | • The industry app has been installed on the smart watch. • The industry app has been authenticated. | • Enable the continuous heart rate measurement switch. • Wear the watch and call the API for subscribing to heart rate data. | For step 2, the corresponding heart rate data is reported. |
| Querying heart rate data | • The industry app has been installed on the smart watch. • The industry app has been authenticated. | • Wear the watch and call the API for querying heart rate data. | For step 1, the query is successful, and the latest heart rate data is returned. |
| Querying resting heart rate data | • The industry app has been installed on the smart watch. • The industry app has been authenticated. | • Wear the watch and remain still for one hour to allow resting heart rate data to be generated. • Call the API for querying resting heart rate data. | For step 2, the query is successful, and the latest resting heart rate data is returned. |
| Querying historical heart rate data | • The industry app has been installed on the smart watch. • The industry app has been authenticated. | • Wear the watch and collect heart rate data. • Call the API for querying historical heart rate data. | For step 2, the query is successful, and historical heart rate data is returned. |
| Querying SpO2 data | • The industry app has been installed on the smart watch. • The industry app has been authenticated. | • Wear the watch and perform SpO2 measurement. • Call the API for querying SpO2 data. | For step 2, the query is successful, and the latest SpO2 data is returned. |
| Querying stress data | • The industry app has been installed on the smart watch. • The industry app has been authenticated. | • Enable automatic stress test and wear the watch to collect stress data. • Call the API for querying stress data. | For step 2, the query is successful, and stress data is returned. |
| Querying body temperature data | • The industry app has been installed on the smart watch. • The industry app has been authenticated. | • Wear the watch and measure the body temperature. • Call the API for querying body temperature data. | For step 2, the query is successful, and the latest body temperature data is returned. |
| Subscribing to SOS events | • The industry app has been installed on the smart watch. • The industry app has been authenticated. | • Call the API for subscribing to SOS events. • Press the power button on the watch for five consecutive times. | For step 1, the subscription is successful, and result code **0** is returned. For step 2, an SOS event is reported. |
| Subscribing to fall events | • The industry app has been installed on the smart watch. • The industry app has been authenticated. | • Call the API for subscribing to fall events. • Fall while wearing the watch. | For step 1, the subscription is successful, and result code **0** is returned. For step 2, a fall event is reported. |
| Starting SpO2 measurement | • The industry app has been installed on the smart watch. • The industry app has been authenticated. | • Wear the watch, call the API for starting SpO2 measurement, and perform SpO2 measurement. | For step 1, when the SpO2 measurement is started successfully, result code **0** is returned. Result code **402** is returned after the measurement ends. |
| Starting body temperature measurement | • The industry app has been installed on the smart watch. • The industry app has been authenticated. | • Wear the watch, call the API for starting body temperature measurement, and perform body temperature measurement. | For step 1, when the body temperature measurement is started successfully, result code **0** is returned. Result code **402** is returned after the measurement ends. |
| Starting the Workout app | • The industry app has been installed on the smart watch. • The industry app has been authenticated. | • Wear the watch and call the API for starting the Workout app. | For step 1, the Workout app is started successfully, and result code **0** is returned. |
| Setting the device information and switch state | • The industry app has been installed on the smart watch. • The industry app has been authenticated. | • Call the setting API. • Use the API for setting basic user information as an example. | For step 2, the setting is successful, and result code **0** is returned. |
| Subscribing to charging status, wearing status, battery level, and heart rate alerts | • The industry app has been installed on the smart watch. • The industry app has been authenticated. | • Wear the watch and call the subscription API. • Call the API for subscribing to the wearing status. Remove the watch and wear it again. | For step 2, the subscription API is successfully called, and result code **0** is returned. After the watch is removed, result code **8** is returned and the value of **wearStatus** is **2**. After the watch is worn again, result code **8** is returned and the value of **wearStatus** is **1**. |
| Subscribing to daily health data updates | • The industry app has been installed on the smart watch. • The industry app has been authenticated. | • Wear the watch and call the API for subscribing to daily health data updates. • Perform daily activities, for example, walk 500 steps. | For step 1, the subscription is successful, and result code **0** is returned. For step 2, result code **10** is returned, indicating that the daily health data is updated. |
| Subscribing to data updates of a single workout | • The industry app has been installed on the smart watch. • The industry app has been authenticated. | • Wear the watch and call the API for subscribing to single workout data updates. • Start a workout (for example, run 100 meters outdoors), and then end the workout session. | For step 1, the subscription is successful, and result code **0** is returned. For step 2, result code **10** is returned, indicating that the single workout data is updated. |
| Subscribing to real-time PPG data | • The industry app has been installed on the smart watch. • The industry app has been authenticated. | • Wear the watch and call the API for subscribing to real-time PPG data. | For step 1, the subscription is successful, and result code **0** is returned. After the PPG data is received, result code **8** is returned along with the data. |
| Querying the device SN | • The industry app has been installed on the smart watch. • The industry app has been authenticated. | • Call the API for querying the device SN. | For step 1, the device SN is queried successfully, and result code **0** is returned along with the device SN. |
| Querying daily health data | • The industry app has been installed on the smart watch. • The industry app has been authenticated. | • Wear the watch, enable automatic heart rate and SpO2 detection, and engage in daily activities. • Call the API for querying daily health data. | For step 2, daily health data is queried successfully, and result code **0** is returned along with the data. |
| Querying daily activity status | • The industry app has been installed on the smart watch. • The industry app has been authenticated. | • Wear the watch and perform daily activities, such as running. • Call the API for querying the daily activity status. | For step 2, the daily activity status is queried successfully, and result code **0** is returned along with the data. |
| Querying data of a single workout | • The industry app has been installed on the smart watch. • The industry app has been authenticated. | • Wear the watch, open the workout app, start a workout (for example, run at least 100 meters), and then end the workout session. • Call the API for querying single workout session data. | For step 2, the single workout session data is queried successfully, and result code **0** is returned along with the data. |
| Querying pulse wave arrhythmia analysis data | • The industry app has been installed on the smart watch. • The industry app has been authenticated. | • Wear the watch, connect the watch to the Huawei Health app, and enable pulse wave arrhythmia analysis in the Huawei Health app. • Proactively or passively trigger a pulse wave arrhythmia analysis. • Call the API for querying pulse wave arrhythmia analysis data. | For step 1, pulse wave arrhythmia analysis is successfully enabled. For step 2, the measurement is successful. For step 3, pulse wave arrhythmia analysis data is successfully queried, and result code **0** is returned along with the data. |
| Querying sleep apnea data | • The industry app has been installed on the smart watch. • The industry app has been authenticated. | • Wear the watch, connect the watch to the Huawei Health app, and enable sleep apnea detection in the Huawei Health app. • Enable TruSleep and wear the watch while sleeping at night. • Call the API for querying sleep apnea data. | For step 1, sleep apnea detection is successfully enabled. For step 3, sleep apnea data is successfully queried, and result code **0** is returned along with the data. |
| Querying resting calorie data | • The industry app has been installed on the smart watch. • The industry app has been authenticated. | • Wear the watch and set a weight loss target in the Stay Fit app on the watch. • Call the API for querying resting calorie data. | For step 2, resting calorie data is successfully queried, and result code **0** is returned along with the data. |
