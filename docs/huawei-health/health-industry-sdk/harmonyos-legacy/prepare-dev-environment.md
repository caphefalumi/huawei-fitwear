# Preparing the Development Environment

#### Installing and Configuring HUAWEI DevEco Studio

- Operating environment requirements For DevEco Studio to function properly, it is recommended that your computer configuration meet the following requirements: Operating system: Windows 10 (64-bit) or macOS 10.14, 10.15, or 11.2.2
- Memory: 8 GB or above
- Hard disk: 100 GB or above
- Resolution: 1280 × 800 pixels or higher

- Installation and configuration processDownload and install DevEco Studio.
- Configure DevEco Studio, including setting the network proxy and downloading the HarmonyOS SDK.
- Run a project to verify the environment configuration.
- Create your project.
