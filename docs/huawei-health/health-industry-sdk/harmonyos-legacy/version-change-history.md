# Version Change History

#### 4.3.0.106 (2024-06-30)

| **New Features** • Added the function of setting device information or switches, including the [language and unit system](https://developer.huawei.com/consumer/en/doc/huaweihealth-Guides/set-language-and-unit-0000002413832940), [raise-to-wake switch](https://developer.huawei.com/consumer/en/doc/huaweihealth-Guides/set-auto-light-screen-0000002447392125), SN](https://developer.huawei.com/consumer/en/doc/huaweihealth-Guides/query-device-sn-0000002447392145). • Added the feature of obtaining daily activity data, including [daily activity status](https://developer.huawei.com/consumer/en/doc/huaweihealth-Guides/query-fitness-status-0000002447352077) and [resting calories](https://developer.huawei.com/consumer/en/doc/huaweihealth-Guides/query-basal-metabolism-0000002447352081). • Added the function of obtaining [data of a single workout](https://developer.huawei.com/consumer/en/doc/huaweihealth-Guides/query-workout-data-0000002413832964). • Added the following functions: [Querying Daily Health Data](https://developer.huawei.com/consumer/en/doc/huaweihealth-Guides/query-daily-health-data-0000002413673072), [Querying Historical Sleep Data](https://developer.huawei.com/consumer/en/doc/huaweihealth-Guides/query-arrhythmia-data-0000002447392149), [Querying Sleep Apnea Data](https://developer.huawei.com/consumer/en/doc/huaweihealth-Guides/query-osa-data-0000002413673076), [Subscribing to Daily Health Data Updates](https://developer.huawei.com/consumer/en/doc/huaweihealth-Guides/subscribe-daily-health-update-event-0000002447591805), [Subscribing to Data Updates of a Single Workout](https://developer.huawei.com/consumer/en/doc/huaweihealth-Guides/subscribe-workout-update-event-0000002414072668), and [Subscribing to Heart Rate Alerts](https://developer.huawei.com/consumer/en/doc/huaweihealth-Guides/subscribe-heart-rate-alarm-0000002447471865). • Added the following subscription functions: [Subscribing to the Device Charging Status](https://developer.huawei.com/consumer/en/doc/huaweihealth-Guides/subscribe-charge-status-0000002413912828), [Subscribing to the Device Wearing data](https://developer.huawei.com/consumer/en/doc/huaweihealth-Guides/subscribe-realtime-ppg-data-0000002413912832). • Added the function of [starting the Workout
