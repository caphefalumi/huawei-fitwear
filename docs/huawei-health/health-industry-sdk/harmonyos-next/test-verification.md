# Debugging and Verification

You need to perform functional verification testing based on the following test cases.

| Test Case | Prerequisite | Step | Expected Result |
| --- | --- | --- | --- |
| Listening to the connection status between the industry app and industry service | • The industry app has been installed on the smart watch. | • Call the API for listening to the connection status between the industry app and industry service. | For step 1, the listener is registered successfully. |
| Obtaining the API level of the server | • The industry app has been installed on the smart watch. | • Call the API for obtaining the API level of the server. | For step 1, the API level of the server is returned successfully. |
| Setting a correct certificate path and performing authentication | • The industry app has been installed on the smart watch. • A correct certificate path has been set. • The smart watch is connected to the Internet. | • Call the authentication API for authentication. | For step 1, the authentication is successful. |
| Setting and querying device information or switch state | • The industry app has been installed on the smart watch. • The industry app has been authenticated. | • Call the setting API. • Use the API for setting basic user information as an example. • Call the query API. • Use the API for querying basic user information as an example. | For step 2, the setting is successful. For step 4, the query is successful and the basic user information is returned. |
| Querying body temperature data | • The industry app has been installed on the smart watch. • The industry app has been authenticated. | • Wear the watch and measure the body temperature. • Call the API for querying body temperature data. | For step 2, the query is successful and body temperature data is returned. |
| Querying stress data | • The industry app has been installed on the smart watch. • The industry app has been authenticated. | • Enable automatic stress test and wear the watch to collect stress data. • Call the API for querying stress data. | For step 2, the query is successful and stress data is returned. |
| Querying historical heart rate data | • The industry app has been installed on the smart watch. • The industry app has been authenticated. | • Wear the watch and collect heart rate data. • Call the API for querying historical heart rate data. | For step 2, the query is successful and historical heart rate data is returned. |
| Querying historical SpO2 data | • The industry app has been installed on the smart watch. • The industry app has been authenticated. | • Wear the watch and perform SpO2 measurement. • Call the API for querying historical SpO2 data. | For step 2, the query is successful and historical SpO2 data is returned. |
| Querying historical sleep data | • The industry app has been installed on the smart watch. • The industry app has been authenticated. | • Take a nap, which lasts more than 30 minutes and less than 2 hours. • Call the API for querying sleep data. • Sleep at night for more than 2 hours. • Call the API for querying sleep data. | For step 2, the corresponding nap data is returned. For step 4, the corresponding nighttime sleep and nap data is returned. |
| Querying sleep apnea data | • The industry app has been installed on the smart watch. • The industry app has been authenticated. | • Wear the watch, connect the watch to the Huawei Health app, and enable sleep apnea detection in the Huawei Health app. • Enable TruSleep and wear the watch while sleeping at night. • Call the API for querying sleep apnea data. | For step 3, the query is successful and sleep apnea data is returned. |
| Querying pulse wave arrhythmia analysis data | • The industry app has been installed on the smart watch. • The industry app has been authenticated. | • Wear the watch, connect the watch to the Huawei Health app, and enable pulse wave arrhythmia analysis in the Huawei Health app. • Proactively or passively trigger a pulse wave arrhythmia analysis. • Call the API for querying pulse wave arrhythmia analysis data. | For step 3, the query is successful and the pulse wave arrhythmia analysis data is returned. |
| Subscribing to heart rate data | • The industry app has been installed on the smart watch. • The industry app has been authenticated. | • Enable continuous heart rate monitoring on the smart watch. • Wear the watch and call the API for subscribing to heart rate data. | For step 2, the corresponding heart rate data is reported. |
| Subscribing to heart rate alert data | • The industry app has been installed on the smart watch. • The industry app has been authenticated. | • Call the API for subscribing to heart rate alert data. • Trigger heart rate alerts. | For step 1, the subscription is successful. For step 2, a heart rate alert is reported. |
| Subscribing to the sleep status | • The industry app has been installed on the smart watch. • The industry app has been authenticated. | • Call the API for subscribing to the sleep status. • Change the sleep status. | For step 1, the subscription is successful. For step 2, the corresponding sleep status is reported. |
| Querying data of a single workout | • The industry app has been installed on the smart watch. • The industry app has been authenticated. | • Wear the watch, open the Workout app, start a workout (for example, run for more than 100 meters), and then end the workout session. • Call the API for querying single workout session data. | For step 2, the query is successful and the data for a single workout session is returned. |
| Subscribing to the workout status | • The industry app has been installed on the smart watch. • The industry app has been authenticated. | • Call the API for subscribing to the workout status. • Wear the watch and start an indoor walk workout. | For step 1, the subscription is successful. For step 2, workout status code **15** is reported. |
| Subscribing to data updates of a single workout | • The industry app has been installed on the smart watch. • The industry app has been authenticated. | • Wear the watch and call the API for subscribing to single workout data updates. • Start a workout (for example, run 100 meters outdoors), and then end the workout session. | For step 1, the subscription is successful. For step 2, a data update event for a single workout is reported. |
| Querying the resting calories | • The industry app has been installed on the smart watch. • The industry app has been authenticated. | • Wear the watch and set a weight loss target in the Stay Fit app on the watch. • Call the API for querying resting calorie data. | For step 2, the query is successful and resting calorie data is returned. |
| Querying the daily activity summary data of the current day | • The industry app has been installed on the smart watch. • The industry app has been authenticated. | • Wear the watch and walk outdoors. • Call the API for querying daily activity summary data of the current day. | For step 2, the query is successful and daily activity summary data of the current day is returned. |
| Querying the daily activity status | • The industry app has been installed on the smart watch. • The industry app has been authenticated. | • Wear the watch and perform daily activities, such as running. • Call the API for querying the daily activity status. | For step 2, the query is successful and daily activity status data is returned. |
| Querying daily activity data | • The industry app has been installed on the smart watch. • The industry app has been authenticated. | • Wear the watch and perform daily activities. • Call the API for querying daily activity data. | For step 2, the query is successful and daily activity data is returned. |
| Subscribing to daily activity data updates | • The industry app has been installed on the smart watch. • The industry app has been authenticated. | • Wear the watch and call the API for subscribing to daily activity data updates. • Perform daily activities, such as walking 500 steps. | For step 1, the subscription is successful. For step 2, a daily activity data update event is reported. |
| Subscribing to SOS events | • The industry app has been installed on the smart watch. • The industry app has been authenticated. | • Call the API for subscribing to SOS events. • Press the Power button on the watch for five consecutive times. | For step 1, the subscription is successful. For step 2, an SOS event is reported. |
| Subscribing to fall events | • The industry app has been installed on the smart watch. • The industry app has been authenticated. | • Call the API for subscribing to fall events. • Fall while wearing the watch. | For step 1, the subscription is successful. For step 2, a fall event is reported. |
| Starting SpO2 measurement | • The industry app has been installed on the smart watch. • The industry app has been authenticated. | • Wear the watch, call the API for starting SpO2 measurement, and perform SpO2 measurement. | For step 1, SpO2 measurement is started successfully. Result code **401** is returned during the measurement, and result code **402** is returned after the measurement. |
| Starting body temperature measurement | • The industry app has been installed on the smart watch. • The industry app has been authenticated. | • Wear the watch, call the API for starting body temperature measurement, and perform body temperature measurement. | For step 1, body temperature measurement is started successfully. Result code **401** is returned during the measurement, and result code **402** is returned after the measurement. |
| Setting network persistence in screen-off mode | • The industry app has been installed on the smart watch. • The industry app has been authenticated. | • Enable network persistence in screen-off mode. • Turn off the screen of the smart watch and check the network connection. | For step 1, the setting is successful. For step 2, the industry app is still connected to the network. |
| Setting app keep-alive | • The industry app has been installed on the smart watch. • The industry app has been authenticated. | • Enable app keep-alive. • Double-tap the Home button and swipe up on the screen to remove the industry app from the background. | For step 1, the setting is successful. For step 2, the removal is successful and the app is restarted immediately. |
| Setting the app to automatically start upon system boot | • The industry app has been installed on the smart watch. • The industry app has been authenticated. | • Enable app auto-start upon system boot. • Restart the watch and check whether the industry app automatically starts upon system boot. | For step 1, the setting is successful. For step 2, the industry app automatically starts upon system boot. |
| Setting the log switch | • The industry app has been installed on the smart watch. • The industry app has been authenticated. | • Call the API for setting the log switch. • Call the API for querying the log switch state. | For step 1, the setting is successful. For step 2, the query is successful and the log switch state is returned. |
