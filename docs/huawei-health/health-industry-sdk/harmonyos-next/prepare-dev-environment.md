# Preparing the Development Environment

#### Installing and Configuring HUAWEI DevEco Studio

- Operating environment requirements For DevEco Studio to function properly, it is recommended that your computer configuration meet the following requirements: Operating system: Windows 10/11 64-bit, macOS (x86) 11/12/13/14, or macOS (Arm) 12/13/14
- Memory: 16 GB or above for Windows, or 8 GB or above for macOS
- Hard disk: 100 GB or above
- Resolution: 1280 × 800 pixels or higher

- Installation and configuration processDownload and install DevEco Studio. For details, please refer to [Downloading Software](https://developer.huawei.com/consumer/en/doc/harmonyos-guides-V5/ide-software-download-V5) and [Installing DevEco Studio](https://developer.huawei.com/consumer/en/doc/harmonyos-guides-V5/ide-software-install-V5#section1453284218345).
- Run a Hello World project to verify the environment configuration after DevEco Studio is installed. For details, please refer to [Creating and Running a Hello World Project](https://developer.huawei.com/consumer/en/doc/harmonyos-guides-V5/ide-hello-world-V5).
- (Optional) [Set up a proxy](https://developer.huawei.com/consumer/en/doc/harmonyos-guides-V5/ide-environment-config-V5). In cases where some enterprise networks are restricted, it is necessary to configure a proxy to access the network.
