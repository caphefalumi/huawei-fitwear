# Applying for the Health Industry SDK Service

Before applying for the Health Industry SDK service, [configure app signing](https://developer.huawei.com/consumer/en/doc/huaweihealth-Guides/configure-signature-info-0000002376394481).

- Register as a developer and complete identity verification. For details, please refer to [HUAWEI ID Registration](https://developer.huawei.com/consumer/en/doc/start/registration-and-verification-0000001053628148).
- Sign in to the [HUAWEI Developers](https://developer.huawei.com/consumer/en/) website and click **Console**.
- Choose** App services** > **Development** > **Health Industry**. > **Note:** If **Health Industry** is unavailable, click the icon next to **Development** to add it.
- Click **Apply Health Industry**.
- Configure app information. 
| Parameter | How to Set |
| --- | --- |
| Product Type | Select **HarmonyOS App**. |
| Select | Select the app created in [Applying for a Release Certificate and Profile](https://developer.huawei.com/consumer/en/doc/huaweihealth-Guides/configure-signature-info-0000002376394481#section5993144222420). (After an app is created in AppGallery Connect, there is an approximate 3-hour delay before it is synchronized to this service.) |
| Application Target Version | By default, **API 5.0.0 (12) and above** is selected. |
| APK Name | The name is automatically filled in after you select a product. |
| Device model | Select the device model supported by your app. Currently, only HUAWEI WATCH 5 is supported. |
| Country/City | Select a country or city. |
| Developer App Name | Enter your app name. |
| Application scenarios of wearable devices for industry applications | Describe the application scenarios of your app on wearables. The description must contain at least 100 characters. |
| Link to the privacy policy disclosed by the app to users | Enter the link to the privacy policy disclosed by your app to users. |
| agreement link | Enter the link to the user agreement disclosed by your app to users. |
| Website link of the enterprise/application | Enter the website URL of your enterprise/app. |
| Enterprise Mail | Enter your enterprise's email address. |
| Enterprise Phone | Enter your enterprise's fixed-line phone number or contact information. |
| Method | • TestSelect a wearable model in **Device model**. • Commercial useSelect one or more wearable models in **Device model**. |

- Click **Submit**, and you will find the app you have created on the page displayed. If the product is in **Test to be reviewed** or **Commercial use to be reviewed** state, wait for the review process to complete. > **Note:** After submitting the application, send the app ID and app entity information to healthindustry@huawei.com for review. After the product passes the review, it will be in the **The test is passed** or **Commercial Use Passed** state. You can then perform the following operations: Click **Manage** to modify the app information.
- Click **Download Certificate** to download the certificate used in the development phase. The validity period of this certificate is three months.
- Click **Converting to commercial use**. In the displayed dialog box, click **OK**. The validity period of a commercial certificate is two years. The **Converting to commercial use** button is unavailable for apps created for commercial use.

- To add device models, click **Manage**. On the page displayed, select these models and submit the request.
