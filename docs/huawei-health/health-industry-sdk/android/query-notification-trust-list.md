# Querying the App Trustlist for Pushing Notifications

This section describes how to query the app trustlist for pushing notifications shown in the notification bar of a mobile device (for example, a phone) to a wearable. When the wearable is connected for the first time, notifications of all apps on the mobile device can be pushed to the wearable by default.

- Call the [getDeviceManageClient](https://developer.huawei.com/consumer/en/doc/health-References/industrywear-0000001434945524#EN-US_TOPIC_0000002678163945__getDeviceManageClient-android_content_Context-) method in [IndustryWear](https://developer.huawei.com/consumer/en/doc/health-References/industrywear-0000001434945524) to obtain the [DeviceManageClient](https://developer.huawei.com/consumer/en/doc/health-References/devicemanageclient-0000001485104693) object.
- Obtain the list of paired wearables by referring to [Obtaining the Wearable List](https://developer.huawei.com/consumer/en/doc/huaweihealth-Guides/get-device-list-0000002372216449). Then, select a target wearable from the list and obtain its ID.
- Construct input data in JSON format for querying the app trustlist for pushing notifications. 
```cpp
{
    "item": "notificationTrustList"
}
```

- Call the [query](https://developer.huawei.com/consumer/en/doc/health-References/devicemanageclient-0000001485104693#EN-US_TOPIC_0000002648084250__query-java_lang_String-java_lang_String-com_huawei_health_industry_client_callback_ServiceCallback-) method to query the app trustlist for pushing notifications. 
```cpp
// Obtain the DeviceManageClient object.
DeviceManageClient deviceManageClient = IndustryWear.getDeviceManageClient(this);

// Obtain the list of paired wearables by referring to Obtaining the Wearable List, select a target wearable from the list, and obtain its ID.
String deviceId = "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx";

// Construct input data in JSON format for querying the app trustlist for pushing notifications.
JSONObject jsonObject = new JSONObject();
try {
    jsonObject.put("item", "notificationTrustList");
} catch (JSONException e) {
    e.printStackTrace();
}

// Call the query method to query the app trustlist for pushing notifications.
deviceManageClient.query(deviceId, jsonObject.toString(), new ServiceCallback() {
    @Override
    public void onResult(int statusCode, String result) {
        // Process the query result.
    }
});
```
 
| Parameter | Value | Description |
| --- | --- | --- |
| statusCode | 0, 1, 2, 3, 6, 7 | Result code of the API call. For details, please refer to the universal result codes in [Result Codes](https://developer.huawei.com/consumer/en/doc/huaweihealth-Guides/errorcode-0000002372870401). |
| result | - | If the API call succeeds, the app trustlist for pushing notifications is returned. If the API call fails, an error message is returned. |

- Process the returned information in the **onResult** method of **ServiceCallback**. The app trustlist for pushing notifications is carried in **result** when the query is successful. 
```cpp
// result example:
{
    "notificationTrustList": [
        "com.aa.bb", 
        "com.cc.dd"     
    ]
}
```
 
| Parameter | Value | Description |
| --- | --- | --- |
| notificationTrustList | ["com.aa.bb","com.cc.dd"] | List of the package names of trusted apps whose notifications shown in the notification bar can be pushed to the wearable. When the [notification push switch](https://developer.huawei.com/consumer/en/doc/huaweihealth-Guides/set-notification-push-switch-0000002372218945) is enabled, only notifications generated by apps in this list can be pushed to the wearable. |
| ["all"] | Default value. When the [notification push switch](https://developer.huawei.com/consumer/en/doc/huaweihealth-Guides/set-notification-push-switch-0000002372218945) is enabled, notifications generated by all apps can be pushed to the wearable. |  |
