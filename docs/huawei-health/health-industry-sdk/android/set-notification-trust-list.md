# Setting the App Trustlist for Pushing Notifications

This section describes how to set the app trustlist for pushing notifications to a wearable. Only notifications from apps in the trustlist will be pushed to the wearable.

> **Note:** An industry app may be killed by the Android system when switched to the background. Make sure to keep your industry app alive or running in the foreground. Before setting the app trustlist for pushing notifications, you are advised to obtain and confirm the apps that have been installed through the Android system API. The notification push feature supports notifications from the following apps or services: SMS, WeChat, QQ, Calendar, missed calls, QQ Mail, AI Tips app, birthday manager (supporting anniversary reminders), and more.

- Call the [getDeviceManageClient](https://developer.huawei.com/consumer/en/doc/health-References/industrywear-0000001434945524#EN-US_TOPIC_0000002678163945__getDeviceManageClient-android_content_Context-) method in [IndustryWear](https://developer.huawei.com/consumer/en/doc/health-References/industrywear-0000001434945524) to obtain the [DeviceManageClient](https://developer.huawei.com/consumer/en/doc/health-References/devicemanageclient-0000001485104693) object.
- Obtain the list of paired wearables by referring to [Obtaining the Wearable List](https://developer.huawei.com/consumer/en/doc/huaweihealth-Guides/get-device-list-0000002372216449). Then, select a target wearable from the list and obtain its ID.
- Construct input data in JSON format for setting the app trustlist for pushing notifications. 
```cpp
{
    "settingKey": "notificationTrustList",
    "settingValue": ["com.aa.bb","com.cc.dd"]
}
```
 
| Parameter | Value | Description |
| --- | --- | --- |
| settingKey | notificationTrustList | Key of the app trustlist for pushing notifications. |
| settingValue | List of the package names of trusted apps. Example: **["com.aa.bb","com.cc.dd"]** | List of the package names of trusted apps whose notifications shown in the notification bar can be pushed to the wearable. The number of these apps ranges from 1 to 255. When the [notification push switch](https://developer.huawei.com/consumer/en/doc/huaweihealth-Guides/set-notification-push-switch-0000002372218945) is enabled, only notifications generated by apps in this list can be pushed to the wearable. |
| ["all"] | Default value. When the [notification push switch](https://developer.huawei.com/consumer/en/doc/huaweihealth-Guides/set-notification-push-switch-0000002372218945) is enabled, notifications generated by all apps in the launcher can be pushed to the wearable. |  |
 > **Note:** When the value of **settingValue** is **[""]** or **["all"]**, notifications of all apps can be pushed to a wearable by default. If you want to forbid the notifications of all apps from being pushed to a wearable, call the API in [Setting the Notification Push Switch](https://developer.huawei.com/consumer/en/doc/huaweihealth-Guides/set-notification-push-switch-0000002372218945) to disable the notification push switch.
- Call the [set](https://developer.huawei.com/consumer/en/doc/health-References/devicemanageclient-0000001485104693#EN-US_TOPIC_0000002648084250__set-java_lang_String-java_lang_String-com_huawei_health_industry_client_callback_ServiceCallback-) method to set the app trustlist for pushing notifications. 
```cpp
// Obtain the DeviceManageClient object.
DeviceManageClient deviceManageClient = IndustryWear.getDeviceManageClient(this);

// Obtain the list of paired wearables by referring to Obtaining the Wearable List, select a target wearable from the list, and obtain its ID.
String deviceId = "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx";

// Construct input data in JSON format for setting the app trustlist for pushing notifications.
JSONObject jsonObject = new JSONObject();
JSONArray pkgArray = new JSONArray();
try {
    jsonObject.put("settingKey", "notificationTrustList");
    pkgArray.put("com.aa.bb");
    pkgArray.put("com.cc.dd");
    jsonObject.put("settingValue", pkgArray);
} catch (JSONException e) {
    e.printStackTrace();
}

// Call the set method to set the app trustlist for pushing notifications.
deviceManageClient.set(deviceId, jsonObject.toString(), new ServiceCallback() {
    @Override
    public void onResult(int statusCode, String result) {
        // Process the return value.
    }
});
```
 
| Parameter | Value | Description |
| --- | --- | --- |
| statusCode | 0, 2, 3, 4, 5, 6, 7 | Result code of the API call. For details, please refer to the universal result codes in [Result Codes](https://developer.huawei.com/consumer/en/doc/huaweihealth-Guides/errorcode-0000002372870401). |
| result | - | Setting result. An error message is returned if the API call fails. |
