# Obtaining a Team ID

Before applying for a certificate, you need to provide your Apple Developer team ID. You can obtain it in either of the following ways:

- Obtain it from the Apple Developer website.Sign in to the Apple Developer website.
- Go to the **Account** page.
- In the navigation pane, choose **Membership details**.
- Obtain the 10-character team ID on the page.

- Obtain it from Xcode.In Xcode, choose **Project** (root directory of the project) at the top of the navigation pane.
- In the **Targets** list in the middle, select your app target.
- Click **Build Settings**.
- Enter **Development Team** in the search box in the upper right corner.
- On the right of the filtered **Development Team** configuration item, view the current team name. Select the team name and click **other**. A 10-character team ID is displayed.
