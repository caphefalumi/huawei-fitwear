# Applying for the Health Industry SDK Service

Before applying for the Health Industry SDK, [register a HUAWEI ID and apply for the HUAWEI ID service](https://developer.huawei.com/consumer/en/doc/huaweihealth-Guides/register-account-and-apply-for-account-service-0000002624668845).

- Choose **App services** > **Development** > **Health Industry**.
- Click **Apply Health Industry**.
- Configure app information. 
| Parameter | How to Set |
| --- | --- |
| Product Type | Select an iOS app. |
| Select | The list is from the products created during [HUAWEI ID registration and HUAWEI ID service application](https://developer.huawei.com/consumer/en/doc/huaweihealth-Guides/register-account-and-apply-for-account-service-0000002624668845). |
| APK Name | The name is automatically filled in after you select a product. |
| Team ID | Apple Developer team ID. For details, please refer to [Obtaining a Team ID](https://developer.huawei.com/consumer/en/doc/huaweihealth-Guides/get-team-id-0000002624549005). |
| Device model | Select the device model supported by your app. You can select multiple device models. |
| Country/City | Select a country or city. |
| Developer App Name | Enter your app name. |
| Application scenarios of wearable devices for industry applications | Describe the application scenarios of your app on wearables. The description must contain at least 100 characters. |
| Link to the privacy policy disclosed by the app to users | Enter the link to the privacy policy disclosed by your app to users. |
| agreement link | Enter the link to the user agreement disclosed by your app to users. |
| Website link of the enterprise/application | Enter the website URL of your enterprise/app. |
| Enterprise Mail | Enter your enterprise's email address. |
| Enterprise Phone | Enter your enterprise's fixed-line phone number or contact information. |
| Method | • TestSelect a wearable model in **Device model**. • Commercial useSelect one or more wearable models in **Device model**. |

- Click **Submit**, and you will find the app you have created on the page displayed. If the product is in **Test to be reviewed** or **Commercial use to be reviewed** state, wait for the review process to complete. > **Note:** After submitting the application, send the app package ID (bundle ID) and application entity information to healthindustry@huawei.com for review. After the product passes the review, it will be in the **The test is passed** or **Commercial Use Passed** state. You can then perform related operations. Click **Manage** to modify the app information.
- Click **Download Certificate** to download the certificate used in the development phase. The validity period of this certificate is three months.
- Click **Converting to commercial use** to change the purpose to commercial use. This button is not available for apps created for commercial use. The validity period of a commercial certificate is two years. Click **Submit** in the dialog box displayed to change the purpose to commercial use.

- To add device models, click **Manage**. On the page displayed, select these models and submit the request.
