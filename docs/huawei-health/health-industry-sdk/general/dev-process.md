# Development Process

#### App Development Process for HarmonyOS 5 or Later

- Use DevEco Studio to create an industry app project and generate a key file and a certificate signing request (CSR) file. For details, please refer to [Creating a Keystore File and a Certificate Request File](https://developer.huawei.com/consumer/en/doc/huaweihealth-Guides/configure-signature-info-0000002376394481#section135084784718).
- Sign in to AppGallery Connect, create a HarmonyOS app, and request a certificate and a profile. For details, please refer to [Applying for a Release Certificate and Profile](https://developer.huawei.com/consumer/en/doc/huaweihealth-Guides/configure-signature-info-0000002376394481#section5993144222420).
- Use DevEco Studio to configure the signing information for the industry app project. For details, please refer to [Configuring the Signing Information](https://developer.huawei.com/consumer/en/doc/huaweihealth-Guides/configure-signature-info-0000002376394481#section1839475132817).
- Sign in to the HUAWEI Developers website and request the Health Industry SDK service. For details, please refer to [Applying for the Health Industry SDK Service](https://developer.huawei.com/consumer/en/doc/huaweihealth-Guides/apply-for-health-industry-sdk-service-0000002342516566).
- Use DevEco Studio to complete the configuration required for industry app development. For details, please refer to [Development Preparations](https://developer.huawei.com/consumer/en/doc/huaweihealth-Guides/dev-preparation-0000002372186745).
- Use DevEco Studio to complete the Health Industry function development for your industry app. For details, please refer to [App Development](https://developer.huawei.com/consumer/en/doc/huaweihealth-Guides/app-dev-0000002372106909).
- Perform functional verification testing on your industry app based on the test cases. For details, please refer to [Debugging and Verification](https://developer.huawei.com/consumer/en/doc/huaweihealth-Guides/test-verification-0000002415520672).
- Release your industry app to AppGallery. For details, please refer to [Compiling and Building the .app File](https://developer.huawei.com/consumer/en/doc/huaweihealth-Guides/configure-signature-info-0000002376394481#section164316581548) and [Releasing the App to AppGallery](https://developer.huawei.com/consumer/en/doc/huaweihealth-Guides/configure-signature-info-0000002376394481#section45808371795).

- Use DevEco Studio to complete the Health Industry function development for your industry app. For details, please refer to [App Development](https://developer.huawei.com/consumer/en/doc/huaweihealth-Guides/app-development-0000002447302125).

For details, please refer to [Building Your App](https://developer.huawei.com/consumer/en/doc/huaweihealth-Guides/configure-signature-info-0000002447309641#section164316581548) and [Releasing Your App/Service to AppGallery Connect](https://developer.huawei.com/consumer/en/doc/huaweihealth-Guides/configure-signature-info-0000002447309641#section45808371795).

#### Android Mobile App Development Process

- Use Android Studio to create an industry app project and generate a signing certificate file and signing certificate fingerprint. For details, please refer to [Generating a Signing Certificate and Its Fingerprint](https://developer.huawei.com/consumer/en/doc/huaweihealth-Guides/generate-signature-cert-and-fingerprint-0000002372130841).
- Go to the HUAWEI Developers website, register a HUAWEI ID, and apply for the HUAWEI ID service. For details, please refer to [Registering a HUAWEI ID and Applying for the HUAWEI ID Service](https://developer.huawei.com/consumer/en/doc/huaweihealth-Guides/register-account-and-apply-for-account-service-0000002338132754).
- Sign in to the HUAWEI Developers website and request the Health Industry SDK service. For details, please refer to [Applying for the Health Industry SDK Service](https://developer.huawei.com/consumer/en/doc/huaweihealth-Guides/apply-for-health-industry-sdk-service-0000002338292522).
- Use Android Studio to complete the configuration required for industry app development. For details, please refer to [Development Preparations](https://developer.huawei.com/consumer/en/doc/huaweihealth-Guides/dev-preparation-0000002338129822).
- Use Android Studio to complete the Health Industry function development for your industry app. For details, please refer to [App Development](https://developer.huawei.com/consumer/en/doc/huaweihealth-Guides/app-dev-0000002372207757).
- Perform functional verification testing on your industry app based on the test cases. For details, please refer to [Debugging and Verification](https://developer.huawei.com/consumer/en/doc/huaweihealth-Guides/test-verification-0000002449159581).
- Release your industry app to AppGallery. For details, please refer to [Releasing an App](https://developer.huawei.com/consumer/en/doc/app/agc-help-releaseapkrpk-0000001106463276).
